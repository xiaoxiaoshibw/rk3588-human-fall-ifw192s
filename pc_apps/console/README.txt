====================================================
 LiDAR 总控制台 (LiDAR Console)  20261010 会话入口收口测试版
====================================================

【运行】
  解压后双击 Console.exe 即可，无需安装 Python 或任何库。
  首次启动 Windows 可能弹 "SmartScreen 已保护你的电脑"
  -> 点 "更多信息" -> "仍要运行"。

【它能做什么】
  新增 USB＋雷达联合录制：板端先存，录制结束后拉回本机。
  录制时相机画面同步录像到本机会话目录（camera.mjpeg + 逐帧索引
  camera_frames.jsonl）；雷达经板端 HC 服务先全量录到板端
  存储，停止后一次性完整拉回本机 captures\remote\<板端会话号>\，
  每次录制独立保存为一个会话目录（目录名就是板端会话号，会话回放面板里
  该行拉回后直接显示本地 ✓，不会重复拉取）。
  可设置本机保存目录与自动停止时长（1–300 秒，板端上限）；拉回完成后
  会话落盘，含 meta.json / points.bin（HC 格式，可被会话回放直接读取）、
  camera.mjpeg（相机录像）/ camera_frames.jsonl 与 joint.json，并在总控制台内自动打开会话回放载入
  该会话；也可在联合录制页下方回看本次相机画面。相机预览中断不影响板端
  录制，已录画面保留；若拉回未完成，板端会话仍可拉取，
  可在会话回放面板重试。
  本机剩余空间不足 256 MiB 时拒绝开始。自定义目录的数据可在会话回放中
  通过“导入目录”打开。

  打开后是总控制台首页，卡片按分类分栏（现在用不到的研究/算法页收进最下面
  「归档」区，默认折叠，点标题展开；页面与代码都还在，没有删除）：
    【采集录制】
      - USB 摄像头     板端 MJPEG 预览
      - USB＋雷达联合录制  板端先存 + 相机同录 · 拉回完成后自动打开回放
    【回放与标注】
      - 会话回放       本地点云会话回放器
      - GT 标注        人工点云标注工作台
    【板端与平台】
      - 板端 WebUI     连接 RK3588 板（需板在线）
    【数据管理】
      - 会话数据库     板端登记 + 本机副本总表；清单（文件/字节/sha256）后
                       分级删除（本机 / 板端 / 两侧）。删除前必须先看清单再确认，
                       且确认该会话没有正在录制/拉回；板端删不动时会如实回报原因。
    【归档】默认收起（6 项）：算法验证（四区评估 TLS/SVD/RANSAC）、人体识别（纯几何
      pin ROI）、人检锁定（B2a RF 51维 · 实时跟踪）、骨架与倒地检测（pointset/r01
      八段动作）、真人倒地回放（r04 原型告警）、小目标跟踪（PLANE-01 纸飞机 3D）。
      要回到可见区：源码里删掉该条 `archived:true` 即可（源码改动，非运行时可切）。

  真人回放使用094333受控倒地会话及131958空场参考。13个显示槽是当前点支撑的粗部位，不是已验证的解剖关节；7.46秒告警是未验证原型事件，confirmed保持关闭。
【系统要求】
  Windows 10 1803+ / Windows 11
  依赖系统自带 WebView2 运行时（Win11 和多数 Win10 已内置）。
  注：应用内如提示需要用 Edge/IE 打开，说明缺 WebView2，
      到微软官网装 "Evergreen WebView2 Runtime" 即可。

【数据目录】
  captures\remote\  — 回放读取的会话数据放这里
                      (cap_xxx 文件夹，含 meta.json + points.bin)
                      可从板端同步，或手动拷入。

【B1 说明】
  人检锁定是诊断/演示性质的第一代实现：
    - 用背景差分 (空场模板) + 5cm 网格连通找人物,
      跟踪 1.5s 断档内保持 track_id
    - 当前只覆盖站立人物 (HR-09 第一批 12 段全部站立);
      姿态 (walk/sit/lying/fall) 和 RF 分类是 B2 的事
    - 空场模板是 2026-10-09 大房间; 换房间 (如浴室) 需重新录模板
      并重新生成 bg_envelope.json (见 源码/human_ml/dump_bg_envelope.py)

【构建与源码】
  桌面“总控制台.lnk”使用 dist\Console.exe，构建命令为：
    python -m PyInstaller --noconfirm Console.spec
  （2026-10-15 起两个总控制台已合并为这一个 exe；Console_Pointset 专版不再构建）
  make_release.py 将该可执行文件与源码一并打入 ZIP。
  源码\ 目录（可选，与构建版本同版）：
  console_gui.py（主程序）、console.html（界面）、Console.spec（打包配置）、
  自测脚本与打包脚本。仅供二次开发参考，运行 Console.exe 不需要。
