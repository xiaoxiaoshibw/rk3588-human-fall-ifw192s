## 2D 距离图 → 身体部位 → 同源 3D（2026-10-26）

运行 `start_body_parts.cmd`（本机服务端口 8947，两个已有会话显式注册），打开
[cap_20261017_113516 第453帧](http://127.0.0.1:8947/?sid=cap_20261017_113516&frame=453)。
脚部候选示例：[cap_20261018_110029 第200帧](http://127.0.0.1:8947/?sid=cap_20261018_110029&frame=200)。旧8946进程保留，但只载入旧条带建议；本轮请用8947。
此入口不连接板端、不采集、不训练。服务已运行时直接打开链接，不重复启动。

默认主工作区是 **2D LiDAR 径向距离图**，不是 XY 俯瞰图。右边复用原 Three.js 3D 视图。
「放大标注区」收起两侧面板；「放大2×」放大真实像素，可滚动查看。

1. 可选左侧已有/新增人物（无人物时用 `candidate_<trackId>`，明确属于未验证的自动目标对应）。已有当前人物整人框时以其 RAW XYZ 范围过滤；否则用当前算法目标源点过滤。整人框与范围内背景纯度均不等于人体分割真值。
2. 选择头部/躯干/上臂1/2/前臂1/2/大腿1/2/小腿1/2/脚部1/2，点「画/重画区域」，直接在距离图拖矩形。矩形为整数显示像素半开区间；自动候选用不规则稀疏像素点集，字段`pixels`为显示方向的`y*width+x`，不以外接框灌满两段之间。只高亮有效且在当前范围中的代表回波，不补洞/背面点。1/2仅为当前帧像面排序分支，不表示解剖左右，也不保证跨帧身份。
3. 可以把部位标为遮挡（保留当前可见矩形或稀疏点集）、不可见、无法判断（后两者清空点集）。重画会以新矩形替换当前区域；删除、部位撤销/重做均在本区。两个部位争用同一源点会拒绝。点击部位按钮、2D 彩色像素或3D点同步选中，当前部位变白，其余按部位颜色显示；未解析点不强行分配。
4. 点「保存部位」「重载部位」「导出映射JSON」。**切帧、换人物前保存**；草稿不跨帧带入。这里的保存/撤销独立于顶部的整人框保存/撤销。默认开发入口写 `body_store_dev/body_parts_v1/<sid>/<frame>/<person>.json`，旧GT、源会话、analysis与历史证据都不改。版本冲突须重载再编辑，不覆盖其他编辑。
5. 点「自动部位候选（含四肢/脚）」无需人工标注便可计算。当前方法`range_topology_branches_v2`保留当前目标实测像素和RAW XYZ邻接（>0.15m不连边、不补洞/桥），四肢仍从脊线分支提出候选。**头部改用中央可见紧凑顶帽，躯干改用中央横截面区域，不再要求头部是端点，也不再从一条躯干中心线截距离填色。** 两者必须与实测主干3D连通；头/躯干内部优先，边缘仍保留有支撑的肢体路径。中央轮廓宽度/区域边界是启发式，不是解剖颈、肩、髋；紧凑低姿没有足够躯干时不造一个大头。**像面向上不等于重力方向**。上下段仍是实测弧长分段，不是肘/膝检测；脚还要求末端转向≥30°、跨度≥45mm和足够源点。所有人体部位准确性UNKNOWN。
6. 无支持的标签显式uncertain且无点集。修复示例：386 f200头部0→137点、躯干515→1045点，脚20/27保持；780 f453头部336→171点（旧头候选过度伸入肩部）、躯干318→916点。f453贴身上臂路径与躯干内部冲突时留空，不再将胸腹点叫上臂；前臂19/62点、小腿97/110点仍有支撑。旧保存文件可原样加载；页面会提示已知旧版自动结果，需点击重算，手工区域保留。两个当前示例已更新独立存储，不动历史证据。旧条带基线`suggest_legacy`不作为缺测补齐。
7. 手动编辑变为human（编辑方式，不代表GT），derivedFrom保留先前来源；刷新建议保留手工/传播部位，合并后由后端重映射，争点拒绝。整人框变化可显式重新过滤，实际范围快照始终保存。propagated须显式fromBinding，当前无跨帧自动传播。原黄色区域骨架保持原候选语义，不改名为真值，不接告警。

每份文档包含会话、帧、人物、源帧/整会话SHA、标定身份、180°方向、坐标单位以及范围快照；后端重算源点与几何，拒绝错绑定和被篡改的已保存映射。`mapping.imagePixels/sourceRows/xyz`一一对应，像素仅拥有ScanGrid选出的最近代表回波（等距取最小源行），不能推断遮挡后方点。`invalidPixels/excludedOutsideScope`分别记录无效与范围外排除；范围内残留背景依旧未验证。

旁路输出部位表面代表点、头—躯干差向量/距离、可辨识表面主轴与各段**无向主轴夹角**；不是关节屈曲角。没有可验证重力/地面时，站立、躺倒、离地高度与跌倒事件保持UNKNOWN，不默认传感器Z等于重力，不改变现有告警。人体部位、正背面与姿态准确性UNKNOWN。

## 一分钟上手

1. 顶部下拉选择会话 → 等首帧渲染（自动取景）。
2. 顶部「画框」→ 画布拖框（没有人物时会自动建 P1 并设为目标），松手自动回「选择」。
3. 点框选中；拖柄缩放、拖体移动；右侧属性面板改 z 范围/可见性/备注/复核。
4. 时间轴：播放/逐帧/倍速/拖动寻址/帧号直达；「复制到下一帧」传播框（origin=propagated）。
5. 右侧可加动作/事件区间（时间轴上显示色条）。
6. 「保存」（原子、冲突提示）、「导出」（浏览器下载 JSON）。
7. 工具栏勾「算法」→「当前帧建议」→ 属性面板「采用/拒绝」；采用后的框保留来源
   （origin=adopted，含算法 id@version），可继续人工编辑。
8. 快捷键仅辅助：Ctrl+Z/Y 撤销重做、←/→ 逐帧（所有功能均有按钮）。

**只想标几帧？** 不需要全 session 标注，校验不要求覆盖：直接跳到目标帧画框保存即可。
左侧「标注帧清单」把稀疏标注变成流程——「每N帧取样」或逐帧加入清单，清单帧在时间轴上
显示空心点、已标帧显示绿色实心，点清单项直接跳帧，保存随草稿持久化。
