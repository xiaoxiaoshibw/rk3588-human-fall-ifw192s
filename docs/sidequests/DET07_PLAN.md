## 2. 评估协议（草案默认值，冻结时逐项确认）

1. **输入**：per-session TLS 配平（复用冻结代码）、z−1.73、I/1023、0.16×0.16×4 体素、柱上限 32（不增容量）；采样臂 `first32`/`z_rank32`/`subvox32`。
2. **匹配**：主=解码框中心与 GT 中心水平距离 ≤0.55 m；辅=BEV IoU≥0.5。
3. **预算口径（修复轮固化）**：FP/帧 = 合并（测试人帧 + 空场帧）；同时报会话 LOSO。
4. **操作点**：仅在 dev 上选（选臂/选 τ）；test 冻结后只评一次；不得回选。
5. **判据（成功标准，建议值，待用户定）**：test 合并预算 ≤0.5 时，候选臂 recall ≥ DET-06 基线（同口径）+ Δ（建议 Δ=0.15 起）；且空场人形固定物最高分 ≤ 操作点 τ。若新数据 ≥2 人，按人分别报告。
6. **前向与失败**：预运行一次性声明预算；断言失败修复后只重跑失败条目；日志保留不覆盖；`python -B -W error` 全程。
