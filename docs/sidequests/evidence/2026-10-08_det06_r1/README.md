## 结论与证据边界

本轮交付：新第二人（C1）四段会话 + 新空场模板的配平与工作区前景；24 帧人框 + 9 空场帧 + 3 个"像人的固定物"硬负例的用户确认与冻结 `gt_eval_v1`；现有 KITTI 权重在冻结协议下的基线评测与指标（74 次前向）。

**基线结果（描述性；单一人、单一场景、24 帧测试集，不报泛化或可用性结论）：**

1. **first32（原版采样）弱**：24 帧原始分 mean 0.03–0.22；误报预算 ≤0.5 框/帧时 recall（中心≤0.55m 匹配）**4.2%（1/24）**；≤1.0 时 **25%（6/24）**；≤0.1 时 0%。
2. **z_rank32（覆盖采样）明显更强**：≤0.5 时 **58.3%（14/24）**；≤1.0 时 **100%（24/24，τ=0.25）**；但该操作点每帧约 0.92 个多余框，且空场同阈值会响。
3. **空场与"像人的固定物"未分离**：空场全场行人最终框最高分 first32 0.20–0.29、z_rank32 0.35–0.54，全部来自 (3.65,-0.41) 的人形固定物（DET-04 已知 0.5 假阳性同源）；用户桌子 0.0、像坐着人的固定物 0.17。要让空场不响需 τ>0.55，此时 z_rank32 recall 只剩约 21%。**"找回人"与"压住人形固定物"在基线上仍不能兼得。**
4. **实现可信度**：4 对照帧 base 结果与 DET-03 存档逐值一致（atol 1e-5）；旧四段 B 前景重生成与 DET-02 原产物 **253/253 逐字节一致**。

边界：不证明人体构成/机制；不报 Precision/Recall 之外的可用性；τ 与预算的对照仅在本 24 帧测试集上；无 p 值/置信区间；空场只有两段模板；E03/G01 保持 BLOCKED，L01/D01 NOT_RUN。
