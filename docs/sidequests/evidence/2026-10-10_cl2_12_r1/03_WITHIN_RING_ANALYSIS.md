# CL2-12 / 03 同 ring 内空间梯度分析 — 2026-10-10

**范围（预注册 P5 边界）**：本文件只回答——"每 ring 常量偏差是否足以解释数据？"（= M1 充分性）。
它**不**排除任何类型的传感器测距偏差，也**不**把任何估计分量命名为真实地面形变或传感器偏差。
数值源：本目录 `03_WITHIN_RING_DATA.json`（脚本 `03_within_ring.py`，输入 SHA 已断言）。

## 3.1 同 ring 内 resid-on-dy 条件分布（FIT 域，ROI2 详列）

ROI2 的 18 个有效 ring（23–40，合并后），每环 dy 跨度 ≈0.24 m（≈6 倍 dx 跨度），**每环内部都有
足够空间覆盖去检验"常量"假设**：

| 量 | 观测（ROI2 FIT，63,959 点） |
|---|---|
| 各 ring resid~dy 斜率 | −0.047 … +0.059 m/m，**符号跨环不规则混合**（+0.019/+0.011/−0.039/…/+0.059/…/−0.045/…） |
| 斜率正占比 | 0.44（18 环中 8 正），跨尺度 w∈{0.05,0.10,0.15} 完全一致（分位数 [−0.047, −0.027, −0.005, +0.011, +0.059]） |
| 5% 剪尾稳健斜率 | 符号/幅值与全量基本一致（|Δ| 多数 <0.015），说明不是尾部离群驱动 |
| ROI1/3/4 | 同型混号（ROI1 [−0.10,+0.10]、ROI3/4 量级更小但方向也不规则），见 JSON `within_ring.ROI1/3/4` |

**结论（STEP3 唯一允许的回答）**：**每 ring 常量偏差不足以解释数据**。ring 内沿 dy 存在系统性、
符号跨环不一致的残差梯度——M1（r = β_g(ring)）在数学上被数据否定（其条件均值结构不成立）。
这一否定**只否定"最简的常量型 B 子型"**，同时相容于：
- g 有真实 y 依赖（地面沿 dy 起伏且各环看到的 y 段不同）；
- b 有 y 结构且与 ring 无固定对齐（如扫描带内非线性测距/几何投影偏差）；
- 非加性/多表面成分（见 3.4）；
**故不据此排除任何 B 的非恒定型式，也不证成 A**。

## 3.2 重叠区相邻环差异（同一 display-x 区间，不同 ring 的残差均值差）

ROI2 FIT：17 对相邻环重叠带内，所有差值均为负（高一环在该带内残差均值更低），
幅度 −3.7 … −17.0 mm，中位 ≈ −7.2 mm：例如 [30,31] 在 dx∈[0.848,0.892] 差 −12.2 mm（n≈3.4k+3.0k）。

- 与 CL2-11 的 frame72 描述一致（曾经报"重叠区平滑过渡、无跳变台阶"，当时只看 300 点均值），
  但 FIT 6.4 万点显示**系统性同号偏差**——这不是"台阶"，却是显著的非零均值差。
- 该观测**同时相容**于：(a) 真地面沿 dx 的坡度在有限重叠带内由不同 ring 的平均入射条件采样不同；
  (b) 逐环平滑变化的测距/几何偏差；(c) 两者叠加。**单看此量仍不可辨识物理归属**。
- 可否定的是"严格意义上每环常量偏差叠加完美平面"这一组合：若是那样，同带内不同环残差应统计一致，
  实测系统差 7–12 mm 显著大于点级标准误（SE ≈ 22 mm/√3000 ≈ 0.4 mm **远小于** 7–12 mm 该差，
  故显著；v1 曾误写 "≫"（audit finding #8 ADOPT 后修正——要证显著应 SE≪差）。

## 3.3 密度/异常值与尺度敏感性

- 5% 剪尾对斜率符号/幅值影响微小（见 3.1）→ 斜率结构非离群驱动。
- 斜率分布对 cell 尺度 w∈{0.05,0.10,0.15} **完全不变**（同一 set of rings 的 slope 不经 cell 重新分箱，
  一致性验证见 `scale_sensitivity`）；M2/M3 的 σ² 随 w 变化但定性结论（M1 不充分）在三个尺度一致。

## 3.4 非加性/多表面保留

M3 的加性结构在重叠区不能完全复现"同带残差仍随 ring 偏移"的细节（M3 的 β_g 只能吸收跨环平均值，
不能吸收同带内环间 7–12 mm 的差加上各自内部斜率）。多表面恒定重叠、视场部分遮挡、单次回波选择等
**非加性因素未被本分析排除**——它只说明"常量型"解释不足，不承诺"加性双因子"即真相。
（可对照 CL2-11 §4：现有数据未见台阶/距离分簇，多表面反证为阴性但未封闭。）

## 3.5 与 STEP1/STEP2 的一致性

- STEP1 判定 ROI2 在三个尺度均单连通、rank 充分（53/53 等）、条件数 28–38 → 二部估计在统计上合法；
- STEP2 的 M3 σ²(训练) 比 M1 降 **13–49%**（w0.05=48.8%、w0.10=26.2%、w0.15=13.3%——尺度相关，
  v1 写 26–49% overstate（audit finding #8 ADOPT 后修订）；cell-only M2 也强 → 与 ring 内梯度自洽；
- 但 STEP2 的 M3 在分组留出/留出帧上**灾难性失效**（见 04）→ within-ring 的"加性可估"现象只存在于
  训练分布内，**不构成可泛化的物理分解**，更不能命名为 g/b。
