# 30 P1 落地：低门槛检测（≥1 点）+ 批量 TBD + KF/M-N 跟踪（含负对照）

触发：用户"继续开发"。实现 `tbd_track.py`（只读 captures/leveled 与 evidence，未碰 data/）。

## 一、实现了什么

1. **检测层**：自由空间前景（离最近静态点 ≥0.22 m）→ 单链接 0.12 m 分簇，**≥1 点即候选**
   （对照：v2 管线 ≥8 点成簇、生产门上 25 点）。实测候选数 **2–10/帧**（均值 ~5.5），没有爆炸。
2. **批量 TBD（速度匹配累积）**：相邻帧候选中心两两配对 → (p0, t0, v) 假设（|v|∈[0.5,8] m/s，
   自动滤掉静止配对），按 r=0.15 m 在全帧累积命中；排序用**"4+1 帧滑窗内最多命中数"优先**，
   避免准静态泄漏簇用"全帧命中"把运动假设压下去（这是本轮实际踩到的坑）。
3. **在线跟踪**：6 维匀速 KF + 自适应门 + M/N 确认（8 帧内 4 次命中）+ coast 8 帧；
   起轨≥3 点；轨道按"位移 >0.3 m 且平均速度 >0.5 m/s"分运动/静止两类。
4. **负对照**：同参数跑"今天无目标的帧 16–26"（同一背景，唯一差别是没有纸飞机）与空场自参考。

## 二、结果（本段 27 帧）

| 项 | 结果 |
|---|---|
| 低门槛候选数/帧 | 2–10（帧 0–26），平均 ~5.5 |
| **纸飞机轨道 ID 4** | 命中 7 帧（9–15）、score 176、位移 1.678 m、平均 2.72 m/s、**confirmed**（第 4 次命中即帧 12 确认） |
| 另一条运动轨道 ID 3 | 帧 9–18、命中 9、位移 0.82 m、平均 0.88 m/s、confirmed；**身份 UNKNOWN**（疑似同伴点/泄漏簇边缘被关联，未混入纸飞机结论） |
| 静止轨道 | ID 2（26 帧、位移 0.05 m）= 持续泄漏簇，被正确分类为 static |
| 批量 TBD | 运动假设 top-3 = 帧 9–13 / 11–15 的纸飞机轨迹（v≈2.3–3.1 m/s）与 1 条漂移泄漏（v≈1.1 m/s）；**纸飞机可宣告发现帧 = 9**（滑窗从 9 开始满 5 命中） |
| 负对照（帧 16–26） | **运动型确认轨迹 = 0**；静止型确认 2（持续泄漏簇，符合预期） |
| 空场自参考 | 前景/簇 ≈ 0（管线自检） |
| TBD 静态配对被滤掉 | 74 个（|v|<0.5 m/s 的配对） |

对照基线：8 点门槛管线同样在帧 9 首次检出（本段纸飞机一出现就有 11 点，属"强目标"）。
**因此本段无法展示 P1 的核心收益（提前发现/极弱点检出）**——那需要新采集里出现"1–5 点级的淡入/远去"段；
P1 的价值在本段体现为：检测层不再依赖点数门槛、确认/丢帧逻辑可复用、负对照干净。

## 三、踩到并修掉的坑（留档）

1. TBD 第一版把**准静态泄漏簇**排到第一（v≈0、命中 27/27）→ 加运动假设过滤 + 滑窗排序（上述 2）。
2. TBD 时间基准写错（用整段首帧作原点）→ 所有假设都只在自己附近命中；
   修为每个假设记录自己的 `t0`。
3. 自由空间门 0.20 m 会收进位移家具（0.17–0.20 m）→ 提到 **0.22 m**（纸飞机最近 0.24 m，仍保留）。
4. 起轨门槛 2 点会产生噪声轨（帧 0–3、帧 18–21 各 1 条假轨）→ 提到 **3 点**，负对照降到 0。
