# CL2-13 / 05 E3 前登记实验设计（只准备，不执行）— 2026-10-10

目标：把 CL2-12 `05_MINIMUM_E3_PLAN.md` 的判别规则**完备化到可授权粒度**。
评审硬性要求："必须提前定义不同观测结果分别支持或排除什么假设、以及什么结果只能维持 UNKNOWN；
否则即使完成测量，也可能再次得到无法归因的数据。"

**边界（冻结）**：本设计不执行、不连板、不采集、不申请设备使用授权。E3-1 / E3-2 实际
采集或物理测量**等待单独授权**。E3-1 **先于** E3-2（布尔结案通道最便宜），E3-2 在
**场景冻结确认**后启动（见 §3 停止条件 S1 升级版）。

## 0. 与 CL2-12 05 的关系

CL2-12 05 给出三包裁决（C 保留+最小、A 收窄保留、B 降级条件触发）与停止条件 S1–S5。本文档**不改判
三包结构**；只做两件事——(a) 把 E3-1/E3-2 的每项都补齐"输入清单 / 精度预算 / 穷尽判别矩阵 /
停止条件触发后的文档动作"四要素；(b) 在判别矩阵中**显式枚举什么结果只能维持 UNKNOWN**。
包 B 保持**不在本轮预注册**（触发条件在 CL2-12 05 已冻结：包 C 排除 D 且包 A 证 g 平面后残差仍在才启动）。

## 2. E3-1 — S01 bag 只读拉取 + 与 S02 逐字段比对（布尔结案）

### 2.1 输入清单

| 类别 | 项 | 规格 |
|---|---|---|
| 设备 | 板端 SSH 通道 | 只读访问 `slam-localization` 容器内 S01 bag 路径；**不得**写入、删除、改权限 |
| 软件 | bag 只读解析 | rosbag-python 只读 reader 或等效；禁止 `rosbag play` 触网 |
| 文件 | S01 bag 本体 | `meta.json` 登记的 SHA 必须在拉取前重算并与记录比对；不一致即 S5 停 |
| 文件 | S02 bin | 本地 `cap_20261009_121647/points.bin`（SHA `97def5d2…`，已由 CL2-13 manifest 复核） |
| 环境 | 触发 | 一次性 short-lived 拉取；保留拉取日志+stdout，落盘 SHA |
| 人员 | 执行者 | 不与 121647 算法开发同一人（盲比）；比对逻辑由第三人 **从冻结的字段表** 实现 |

### 2.2 测量精度预算

bag 是**数字产品**（含录制时刻的固定字节）；比对是逐字段 **`==`**，无仪器误差。仅有的不确定度是
**解释层**：bag 的 frame 顺序/topic 与 bin 的行的映射必须以 `meta.json` 里预存的 frame 序号
对应关系为唯一锚；若 S01 bag 的 frame 数 ≠ meta 声明 → 本身即字段不一致（判 D 成立）。
无重复测量要求；**一次拉取足够封闭**（bag 静态、SHA 锚定）。

### 2.3 结果→假设判别矩阵（穷尽）

| 观测结果 | 支持 | 排除 | 文档动作 |
|---|---|---|---|
| 全部检测字段（序列、时间戳、点级 x/y/z/intensity/ring、点数）逐点一致 | A/B/C 任一仍开放；**D 封闭** | D | 121647 数据纯净性确认；E3-1 完成；进 E3-2 冻结确认 |
| 任一字段不一致（序列跳、时间戳乱、坐标分量失配、ring 值异常、点数不等） | **D 成立** | A、B、C 均不用继续（原因是提取层伪影） | **全线冻结**（见 §3 S5）；不启动 E3-2；121647 修复条件继续 BLOCKED，问题移交采集/提取链 owner |
| bag 不可得 / SHA 与 meta 记录不一致 / 文件破旧 | 不能判 D | 无 | UNKNOWN（见 §3）；不得以"数据老化"强行解读 |
| bag 可读但字段表在 meta 中缺失（无法预注册比对字段） | 不能判 D | 无 | UNKNOWN；先补 meta，再谈比对 |

**没有任何"部分一致"的合法出口**——一致即一致，任一字段不一致即 D 成立；中间态 UNKNOWN。

### 2.4 停止条件（E3-1 内部，触发即停）

触发任一条即停，写明状态并保持 121647 BLOCKED：
S1-a bag 不可得 → UNKNOWN；S1-b SHA 与 meta 不符 → UNKNOWN（可能被人改动板端文件，另案追查）；
S1-c 字段表不全 → UNKNOWN；S1-d 拉取/解析过程报错 → UNKNOWN，真实报错存档，不重试超 3 次。

## 3. E3-2 — ROI2 9 点×3 重复独立几何 g 锚点（九点水准）

### 3.1 输入清单

| 类别 | 项 | 规格 |
|---|---|---|
| 设备 | 激光水准仪 / 旋转激光水准 | 精度 ≤ ±0.2 mm/m、量程覆盖 ≤ 5 m；最近校准日期 ≤ 6 个月；**附证书照片落盘** |
| 设备 | 数显倾角仪（平板姿态备用，包 B 用） | 精度 ≤ ±0.05°；同上校准票据 |
| 设备 | 辅助：水准泡+平尺 / 三脚塔尺 | 塔尺分度 ≤ 1 mm |
| 文件 | 测区基准标识 | ROI2 display 盒 [0.75,1.0]×[−0.25,0]（CL2-12 05 冻结）；4 基准点在 ROI2 外选择**已知水平**面（水准泡+平尺核验） |
| 环境 | 场景冻结 | 121647 采集时刻至测量时刻 ROI2 物理区域**无任何改动**；测量前由非作者第三人巡视存证（**照片+签字落盘**） |
| 人员 | 读数录入 | 第三人未参与点云分析；对照比较由第四人独立执行 |

### 3.2 测量精度预算

目标效应量级：121647 残差结构 45–61 mm（P95）。需把读数合成不确定度压到 **≤ 3 mm 标准差**
（≪ 45 mm，保有 ≥10× 信噪比）。来源预算：

| 来源 | 量级 | 处理 |
|---|---|---|
| 水准仪自身 | ±0.2 mm/m × 工作距 ≤ 5 m ≈ ±1 mm | 不重复可观 |
| 塔尺读数估读 | ±0.5 mm | 3 次独立读数取中位 |
| 点位对准 ROI2 名义盒的物理偏差 | 名义盒定义误差 ≤ 2 cm（CL2-12 05）；垂直读数 ≠ 斜向读数 | 水准十字激光在地面投影定位，±5 mm；**该偏差不进高度读数**（只进点位对应） |
| 地面表面微粗糙（非形变） | 实测决定 | 每点 3 重复以标准差报告；S4 触发即 UNKNOWN |
| 时间稳定性 | 121647 之后是否再动 | 靠 S1 场景冻结与 S5 baseline 不变性 |

合成：典型工作距 3 m 下 √(1²+0.5²+misc²) ≈ **1.4 mm**，3 重复后 ~**0.8 mm** σ̄。
预注册触发门 S4："3 重复 SD > 3 mm" 即停（给 2× 余量）。

### 3.3 结果→假设判别矩阵（穷尽）

读数：每点 3 重复取中位 → 9 点相对高程 + 4 基准核验（基准点应共面±1 mm 内，否则仪器
自校 FAIL → S3 停）。

设 9 点拟合平面（最小二乘）后残差的 P95 为 `g_resid`：

| 观测结果 | 支持 | 排除 | 文档动作 |
|---|---|---|---|
| 基准 4 点共面 ≤ 1 mm；9 点 `g_resid` ≤ 3 mm（地面实为平面、仪器噪声内） | B 或 C（点云看到的 45–61 mm 结构化残差**不来自地面几何**） | A | g 平面已知 → 残差归因于 B/C；包 B 由 CL2-12 05 条件触发门判罚是否启动（"g 平面且残差仍在→启动并对 dy 混号梯度重新预注册"） |
| 基准 4 点共面 ≤ 1 mm；9 点 `g_resid` ≥ 45 mm 且空间分布与点云残差**空间对齐**（同 dx 段带、同 y 依赖形状，CL2-12 03 同环梯度比照） | **A**（真地面形变） | B 的"常量+平滑随 ring"型、D | TLS 源法向失效；问题移交**场景 owner**（不是算法 owner）；121647 修复 BLOCKED 继续保持 |
| 9 点 `g_resid` ≥ 45 mm 但空间分布**与点云不一致**（形状不对齐） | A 部分成 + B/C 残余并存 | 无法干净分离 | **UNKNOWN**——不得以"差不多"凑支持 A |
| 9 点 `g_resid` 3..45 mm（中间带） | 地面有真实小形变但不足以解释点云 45–61 mm；B/C 残余并存 | 单一 A、单一 B 均不可完全解释 | **UNKNOWN**——不是"差不多 A"；按评审"什么结果只能维持 UNKNOWN"的硬要求，**中间带必须 UNKNOWN** |
| 9 点 `g_resid` ≤ 3 mm 但**基准点本身不共面** > 1 mm | 不可判（仪器/读数错误不可测） | 无 | UNKNOWN；仪器送校、重做 |
| 场景冻结确认失败（巡视发现 121647 后 ROI2 已动） | 不可判 | 无 | **UNKNOWN + E3-2 作废**；E3-1 仍有效；121647 保持 BLOCKED |
| 仪器自校 FAIL / 重复 SD > 3 mm / 点-面对应 >2 cm | 不可判 | 无 | UNKNOWN |

**显式 UNKNOWN 格子**（评审要求）——以下观测**只能**给 UNKNOWN：
中间带 `g_resid` 3–45 mm；g 形变但形状不对齐点云；基准不共面；场景冻结失败；仪器自校失败；
点-面对应误差 >2 cm。**禁止**在这些形态下说"支持 A"或"支持 B"。

### 3.4 停止条件（升级为完整版，含触发后文档动作）

| 编号 | 条件 | 触发后动作 |
|---|---|---|
| **S1** | 场景冻结被推翻（121647 后 ROI2 物理区域有改动） | E3-2 **作废**；输出 UNKNOWN；不启用替代解释；E3-1 已完成的结论保留；121647 BLOCKED |
| **S2** | 点-面对应误差 > 2 cm（名义盒与物理对位失败） | 该点读数作废；若致 9 点不足 8 个有效点 → UNKNOWN |
| **S3** | 仪器自校 FAIL（基准 4 点不共面 >1 mm） | 整轮读数作废；仪器送校；UNKNOWN |
| **S4** | 3 次重复 SD > 3 mm | 该点读数作废；若有效点 <8 → UNKNOWN |
| **S5** | 包 C（E3-1）检出字段不一致 | **全线冻结**，优先于 E3-2；E3-2 不启动；121647 BLOCKED |
| **S6** | 基准 4 点共面 1..2 mm 中间带 | 降级精度预算重新核算；若合成后 σ̄ > 3 mm → UNKNOWN |
| **S7** | 测后比对发现读数录入与原始照片不符 | 该次读数作废；第三/第四人对质后统一重录； UNKNOWN until resolved |

**总闸门**：任一 S 触发 → 停止 → 写明状态 → **不得换方法压数据** → 121647 修复条件继续 BLOCKED。

1. E3-1（bag 比对）**先做**。S5 若触发则全线冻结，E3-2 不启动。

  ping 板端 SSH 元数据，这事本身需要授权（不属于本轮 CL2-13 范围）。

- 包 B 平板方案**未预注册**（沿用 CL2-12 05 的"条件触发"降级判决）。
