# CL2-11 / 02 证据可辨识性分析 — 2026-10-10 Asia/Shanghai

本文件回答：**现有资料能否区分 A(真地面非平面) / B(传感器测距偏差) / C(多表面混入) /
D(解码/变换/提取链错误) / E(不可辨识组合)。** 结论是数学层面的，不宣称任何物理因果。

## 1. 证据等级定义（沿用 CL2-09A/09C/10，未改）

- **E1** 原始行绑定 + 独立计算的直接数值证据（最强；仍局内）
- **E2** 预注册单变量算法/坐标反事实（强于关联，只证明机制）
- **E3** 独立真实几何/点身份/设备干预证据（本轮**仍然缺失**）

## 2. 残差是否随物理空间坐标系统变化？（回答重点①）

**会变化，但变化是纯旋转/刚体性的，信息不变。** CL2-10 T103 已执行固定行域的配套刚体
(±1° 旋转，[0.1,−0.2,0.3] 平移) 对照：逐点 signed distance 差 ≤8.9e-16 m，即残差对刚体坐标
选择**不变**（这正是平面的性质，TLS 距离是坐标无关的）。因此残差结构不是坐标系选择
制造出来的假象，但坐标变换也无法“消掉”非共面——它只说明这不是 D 的坐标变换错误
子型（如果变换错了，位置不变性不会成立到机器精度）。

证据：E1（对角/逐点验证）+ CL2-10 01_root_cause.md §B。**不能把“坐标变换下不变”
扩大为“外参已校准”——数学表示正确 ≠ 物理安装角正确。**

## 4. 是否存在多表面混入的可重复证据？（回答重点③）

直接证据**没有**。康截：(a) 每 ring 内部 display-x 重叠平滑；(b) CL2-10 的 5cm 格全部多 ring 覆盖
（multiring fraction=1.0）；(c) frame72 ROI2 每环 P95 在 0.028–0.057 之间连续变化，未见模态分裂
（双峰/台阶）；(d) 09A 的 25 格均值图跨帧相关中位 0.988，说明结构**空间稳定**而**不是**随机回波
交错。
但“没有观测到多表面证据” ≠ “证明没有多表面”：若两个表面在 ROI2 盒内**始终**重叠于同一批 ring
且高度差恒定在几 mm–几 cm，将产生与真实起伏无法区分的连续场。**反向判据**（如果多表面存在，
在什么观测下会露馅）是：同格多 ring 时残差按 ring 呈现台阶差，或同 ring 内出现**距离分簇**
（同一束光跨前后两个表面）。现有数据未见台阶/分簇，但置信度受限于 ring↔位置混淆——同一束
光在盒内只打一处。判 C 揭穿需要 E3（独立身份/多角度/时间触发），本轮 E3 缺失 → **不能排除 C，
也不能证成 C**。

## 5. 刚体坐标变换是否符合预期残差不变性？（回答重点④）

**符合**（见 §2）。这一条把 D 的“坐标/变换实现错”子型进一步压缩：如果变换矩阵应用错，
固定点集的刚体不变性会在量级远大于 1e-16 处被破坏。数学链上 D 只剩“bag→bin 重构错”
（提取/解包）子型还可能，而那正好是 STEP3 的复解码对照对象。

## 6. 测量偏差与真实起伏是否可分辨？（回答重点⑤，核心）

**在当前已执行的一维分析口径下：不可分辨。** 这个结论在**更精细的二维分解**下是否能突破，本轮**未判定**
（审计按提示词点出的一个未尝试判别量；见下）。形式化：

- 观测模型：每个测量点 p_i 是真实地面 g(q_i) 与传感器偏差 b(q_i, c_i) 的和（q_i=真地点，c_i=ring/通道）。
  p_i = g(q_i) + b(q_i, c_i) + ε_i。
- 在 ROI2 内，c_i 与 q_i 的 display-x 分量高度相关（scanning 决定了“看到盒内某 x 的光基本来自某一
  ring 段”，相邻环 x 重叠中位 ≈64%）。把每点近似为 (display cell, ring)，观测方程为
  r ≈ h(cell) + β(ring)。该二部图连通 → h 与 β 可**估计到一个全局常数**（这正是 OpenCode 审计指出的
  未尝试判别量）。**但**估计出来的 β(ring) 是测量学量；把它命名为“传感器测距偏差”还是
  “地面真实几何在扫描带上的投影变化”需要**额外假设**或 E3。因此：
  - 一维口径：不可分辨（欠定 + 混淆）。
  - 二维口径：**本轮未做**——只能承诺“可估计出两个主成分”，不能承诺“分解结果即物理 g/b 归属”。
- 我们**没有任何**独立于 b 的 g 观测（没有 RTK/激光跟踪仪/水准/已知平板），也没有独立于 g 的 b
  观测（没有厂商通道标定/换台雷达/换角度重看同一点）。
- CL2-09A 的 temporal/equal-weight/local-plane 反事实只能说明 f(x) 在数据内有稳定数值趋势，
  **不能**把“f(x)”归因给 g 或 b——这是 CL2-10 已经标明的 E2 级机制证据，不是 E3。

**结论**（审计修正后）：重点⑤ = 在已执行口径下不可分辨（UNKNOWN），二维分解/ y 内分解是未尝试
的潜在判别量；即便做，仍**不能**不借助 E3 就把 β 命名为“传感器偏差”或把 h 命名为“真地面”。
