## 4. 标签诊断

1. **GT 的 z_min≈0.16 m 已证伪"真实脚部"**：24 帧全部满足"圆柱内**未被空场模板解释**点的最低 z == GT z_min"；0.10–0.16 m 的点 93–100% 被模板"解释"掉。这是标注脚本 `explained_mask`（空场占据 ±1 体素）把贴地点归入地面的系统性截断——**不是人的真实 z 下界**（B 前景里有 z=0.10 起的点）。影响：框底/框高与 IoU 口径，中心匹配不受影响。
2. **114340（左隔板旁）另有肢体缺失**：0.3–0.6 m 带中 40–163 个点被模板解释（其他三组该带解释数 0–2），GT 框在下肢方向比另三组更小。与"站位紧邻隔板"一致，属于模板法的邻接伪影。
3. **人形固定物 #0 的冻结结构不完整**：冻结 aabb z 0.15–1.41 m（n=509），而同圆柱（r=0.55）实测 z 最高 **1.91 m**（134 点在 1.42–1.91 m，强度更低）；简报里的"高约 1.9 m"与圆柱一致、与冻结结构不一致。用于"最高分来源"定位没问题，但结构描述不完整。
4. **用户确认文本自相矛盾需再确认**：冻结 `user_confirmation` 里用户原话是"（#2）是一个坐在椅子上的人；（#0）是一个人""#2 绿 #0 橙 是人"，而记录判定把它们改记为"人形固定物（非真人）"；标注脚本的 `note` 在用户确认前就写了 `user confirms as non-person furniture`。当前简报称"用户确认非真人"——两者需要一次显式澄清，并把冻结文本与判定对齐（否则 GT 的语义基础不牢固）。
5. **匹配半径不是问题**：recall 在半径 0.3/0.4/0.55 m 下完全相同（所有命中框都 <0.3 m）；FP 计数在 0.3 与 0.55 下也相同（0.3–0.55 m 环带内没有框）。**匹配半径既不宽也不窄，无需调整**。
