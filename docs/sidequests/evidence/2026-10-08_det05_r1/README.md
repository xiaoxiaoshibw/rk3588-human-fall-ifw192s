## 方法与预注册要点

- 标注协议（[DET05_PLAN.md](../../DET05_PLAN.md)）：scope = 水平距种子 ≤1.0m、leveled z ∈ [0.05,2.30]；z ≥ 0.15 按 r_link=0.08m 单链聚类（cKDTree，xyz）；人体块 = 满足 n≥50 且 z_max≥1.2m 的簇中水平质心距种子最近者；其余 z≥0.15 簇 n≥10 与近地带为 furniture，n<10 碎片为 mixed_uncertain；作者初标 + **用户确认后冻结**；未标点不默认背景。
- 冻结件：`artifacts/det05_r1/frozen/{labels_v1.json, gt_v1.json, freeze_manifest.json}`；gt_v1 含每帧 human prepared/raw 行列号、XY 质心、z 顶、AABB、provenance（确认原文、标签/渲染 SHA、各会话 TLS 变换 SHA）。冻结后未再改动。
- 纯度与切换：`pure = 柱内全部有效点标签均为 human`；base = 全柱 first32；pure_switch = 仅纯柱 z_rank32（沿用既有 z 排序等距取 32 语义），其余柱张量/计数/坐标/槽位逐值断言与 base 相等（10 独立检查逐柱复核，含 base switched 掩码必须为空）。
- 指标：GT 位置分三口径（GT 0.55m 内 anchor 原始最高 / 解码框包含 GT / 最终框包含 GT）；GT 匹配 anchor = 全 anchor 中中心距 GT 最近者，报告全库与局部排名；竞争位 = 最终行人框中中心距 GT ≥0.8m（预注册最小分隔）最近者及其分与边距；框空间匹配 = 包含 GT 的最终框与 gt AABB 的 2D IoU（Shapely）。不用全场最高/跨帧中位冒充识别指标。
