## 回答“为什么分低”

上一轮我只把配平后整场点云送给PointPillars，确实没有接项目的背景模块，不能把那个结果直接当完整项目管线效果。本轮已经接入独立无人模板，并将裁剪、背景删除、配准、cleanup拆开对照。

**背景删除正常生效，保留下来的人形仍然被这套预训练权重打低分。** 工作空间总点数从约2.3万降到约3800–4500；用户定位圆柱相对workspace输入仍保留99.73%–99.78%。这个圆柱不是逐点人体GT，不能称精确人体保留率。参考模板同会话独立留帧（51帧构建，17/35/53三帧检验）背景删除99.75%–99.77%，见09文件。这证明本次背景操作有效，不证明任何场景都能正确去背景。

已查到两个进一步的证据：

1. **网络输入的体素截断损失很大。** 模型每个0.16m×0.16m柱最多取前32点。四组中间代表帧的定位圆柱，前景1204–1878点，在这一步只剩272–356点，约17%–23%；215540上半身z≥1.5m的164点剩8点；215623举手最高2.010m变成1.828m。原始输入/背景前景轮廓完整，不代表实际进入编码器的全部形状完整。这里只量化了丢点，没有通过改变采样的模型对照证明其是低分唯一根因。
2. **低分在NMS之前已经出现。** 在相同代表帧、真人定位点0.55m范围的anchor上，E分支分类头最大Pedestrian分数仅0.030/0.074/0.069/0.070，均低于原0.1输出门；因此不能只归咎于NMS删了一个高分真人框。对应B分支0.056/0.233/0.303/0.356。anchor邻域只是诊断，不等同于解码后真实框，详见12文件。

当前权重来自KITTI三分类整场LiDAR实现：[固定上游源码/数据说明](https://github.com/zhulf0804/PointPillars/blob/620e6b0d07e4cb37b7b0114f26b934e8be92a0ba/README.md)。本场景是约2.2m的高密度俯视IFW192S，且输入前景化；从本轮“人体邻域基本保留但分类头分数下降”看，**结果更支持预训练输入域/特征适配不足**，这是推断，尚未靠重训练或采样控制实验确定主因。强度除1023和Z偏移-1.73也是尚未独立标定的适配假设，本轮固定它们以隔离背景影响。
