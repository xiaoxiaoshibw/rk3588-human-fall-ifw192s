## 2. 评估协议（预注册项；P02 冻结后不得事后更改）

1. **样本单位与切分**：帧为样本；同一会话的帧不得跨 dev/test 混用（按时间块切分）；可得时优先按人/场景整体隔离，其次会话，最后时间块；DET-03/04/05 已分析过的帧/会话一律计为"已开发"，test 优先取未分析数据。13466 人体点不构成独立样本，禁止把点级计数当样本量。
2. **评估区域**：沿用既有工作区/模型输入范围（默认，见第 6 节默认值 5）；区域内**全部人必须标注**（区域完整标注），FP 只在区域内计数；区域外框不计数、单列。
3. **GT（gt_eval_v1）**：逐帧人框（BEV，含底高与高度）；人形硬负例结构单独标注（如 233658 anchor 158179 对应约 1.9m 结构，DET-04 H-D）；无人帧清单。流程复用 DET-05 模式：确定性提案 + 渲染 + 用户确认 + 冻结（帧集/变换/标注 SHA/provenance）。
4. **匹配口径**：主 = 解码框中心与 GT 框中心水平距离 ≤0.55m；辅 = BEV IoU ≥0.5；一个 GT 至多匹配一个框（按分数降序贪心）（默认，见第 6 节默认值 7）。
5. **操作点与指标**：全分域 PR 曲线；预声明 FP 预算 {0.1, 0.5, 1.0} 帧均（默认，见第 6 节默认值 6）下的 recall；硬负例（空场帧/人形结构）各操作点响应与最高分；辅助沿用 DET-05 口径（GT 匹配 anchor 分/全库排名/≥0.8m 竞争位边距）。dev 上选操作点，test 冻结后只评一次。
6. **输入定义冻结**：per-session TLS leveling（冻结 SHA）、z−1.73、I/1023、0.16×0.16×4 体素、32 点/柱；主臂 = first32（上游语义），辅臂 = z_rank32（已实现，仅对照、不择优；默认，见第 6 节默认值 4）；score 0.1 / top100 / NMS 0.01 / max50 不变。不改权重/上游/编码。
7. **前向与失败**：前向预算在预运行一次性声明；断言失败修复后只重跑失败条目，日志保留不覆盖；`python -B -W error` 全程。
8. **口径声明**：DET-06 不判定"适配成功"，只输出基线数值与跨会话/跨帧稳定性；操作点选在 dev，test 不得参与任何选择。
