## 问题与待检验解释

上一轮PointPillars输入是配平后整场有效点，确实未接项目背景去除。真人完整点已由用户确认，真人位置分数约0.11–0.29，而较高分框在其他位置。不能把低分直接归因于“缺人体点”。可能因素包括背景/家具在特征网格内干扰、人体与家具空间接近、预训练KITTI与近距俯视IFW192S域差异、强度响应差异、hard voxel每柱32点的截断与top-k/NMS。背景去除是本轮首先检验的一项原因，不能提前保证它一定提高分数。

当前项目同时存在：含人会话自建静态图build_static_map，以及独立空场build_reference_map。自建图吸收长期静立人是已知边界，现有四会话probe已量化复现；本轮不得从四个含人会话构建具有删除权的背景模板。它们的静态图只可用于已有ICP的静态几何对应搜索，不对人体做自背景删除。

## 开发步骤

1. 核对五会话本地meta/bin、帧数、布局/源SHA。记录原主树branch/HEAD、所有Git文件含未跟踪SHA；模型支线源码也冻结。确认233658是无人空场；未获确认前只执行其配平和输入检查，不授予模板删除权。
2. 新模板用本分支既有auto地面算法离线配平，保存TLS/SVD/RANSAC及留帧门。四个人体会话复用已有本分支有效TLS并核源SHA；如源变动重新配平。215607跨算法冲突保留，仅诊断TLS有效，不提升为正式推荐。每组R/t都来自自身录制，不跨会话套用。
3. 冻结当前项目 human_pipe_lib.js / human_replay_lib.js / registration_method.js 与调用数学函数必要源码副本、hash。正确28B→XYZI，源XYZ=0在旋转平移之前剔除；保存原行索引，不修改 captures。
4. 在配平空场帧上复用build_reference_map，固定现行occupancy候选门0.5；模板锁定、记录参数与摘要，后续四个会话不可更新模板。空场与含人会话坐标独立配平后仍可能存在细微偏差，复用既有fixedICP做ref→current估计，明确逆变换current→ref供匹配；不把历史特定会话ICP_SAVED回归字段当本次新会话质量结论。跨会话配准只用于离线对照，不走production gate自动接管。
5. 用以下固定输入分支做253帧PointPillars CPU对照；全程同checkpoint、原score阈值0.1、强度除数1023、model z偏移-1.73、4线程。保留predictions、来源、逐帧点数与时延。

| 分支 | 输入 | 对照目的 |
|---|---|---|
| A_full | 配平有效点整场 | 复现上轮输入 |
| B_workspace | 既有denoise + z∈[0.10,2.50]；无背景删除 | 把地面/顶棚裁剪影响与背景删除分开 |

6. 使用用户四个固定XY种子/r=0.55m,z∈[0.05,2.30]逐帧记录前后点数（圆柱仅诊断，包含邻近家具，非逐点人体GT），同时记录上半身/举手高度带是否被剔除。基于旋转预测框包含用户XY点，比较真人位置最大分/覆盖帧/预测高度；全场最大分另列，不能当真人分数。没有逐帧准确框不报P/R，不通过降低score阈值冒称改善。
7. 检查背景匹配的点身份、强度和current坐标恢复；合成例证明固定空场删除背景、保留模板中没有的静立人；验证自建图会吞静立人的负对照，以及配准矩阵方向/逆变换。检查source/模板/模型/核心源码SHA前后相同。绘制代表帧的整场/前景与预测框对照，生成报告和按ID回传。

## 失败与停止条件

空场属性未确认、源SHA改变、模板TLS质量门失败、配准非法或核心回归失败要公开BLOCKED/FAIL；不改门槛绕过。配准收益为诊断，需要保存残差和方向检查，不声称正式注册gate PASS。背景删掉真人种子邻域太多时直接报告，不临时增加保护圈制造好结果。CenterPoint原依赖阻塞保持，本轮先把已可运行的PointPillars输入对照做完；不把它写成两模型均完成。

设备/部署/新采集/物理标定/主线接管均NOT_RUN；不commit/push，不覆写旧证据或用户数据。
