## 1. 可迁移的原则

| # | 原则 | 来源 / 说明 |
| --- | --- | --- |
| 1 | 情境感知优先：一眼回答「现在什么状态、有没有异常、异常在哪」 | ISA-101 的目标写的是减少操作员失误、提升 situational awareness |
| 2 | 显示分层：总览 → 单元 → 细节 → 诊断；一页一个主任务 | ISA-101 的 display structure / navigation |
| 3 | 颜色语义化：常态低饱和，颜色只给「偏离正常」，同色同义 | HPHMI 通行做法（经验） |
| 4 | 关键信息位置固定，变化靠数值/趋势，不靠闪烁和动画 | HPHMI 经验 + 操作员肌肉记忆 |
| 5 | 一致性：同控件同行为，危险操作统一确认，快捷键可发现 | 通用交互 |
| 6 | 密度可控：数字优先、单位紧跟、字号阶梯固定（≥12 px） | 通用可读性 |
| 7 | 性能即体验：不阻塞 GUI、不可见元素不干活、绑定简单、别逐帧重建大数组 | Qt Quick 性能文档（明确列出 clip、invisible、复杂绑定、序列逐元素写回等） |
| 8 | 可观测：错误贴近动作出现，并带时间/阶段，能追溯 | 本站已有 `nativeStderr.atMs` 的思路 |

## 3. 建议顺序

**P0（收益最大，风险小）**

1. 顶部状态条 + 固定字号阶梯 + 颜色角色表（normal / info / warning / alarm / selection 五色，写进 README）。
2. 帧号/总帧数贴滑块；空格、←/→、Home/End、Esc。
3. 空状态文案（未注册 analysis）。
4. `setFrame` 惰性化（标注页不可见时不拷贝）。

**P1**

5. 会话列表单行 + 过滤 + 删掉死属性。
6. 3D 坐标轴与色带图例；框选结果并入状态区。
7. 错误/告警就近显示（状态条红点 + 一行 toast），替代底部一行 `viewer.status`。

**P2**

8. 记住窗口尺寸/位置/上次会话（QSettings）。
9. 把「会话回放」拆成总览/帧详情两层，降低单页密度。

## 4. 不建议做

- 不加装饰性渐变、发光、粒子动画；HPHMI 明确反对用动画吸引注意力。
- 不把所有指标做成彩色卡片；颜色一多，告警就没有语义。
- 不把 3D 当背景装饰；每个交互都要能回答一个具体问题。
- 不在 QML 里逐帧重建大数组或整帧拷贝（Qt 文档点名的反模式）。

## 5. 怎么验收（可自动化）

- 扩展 `--tour-report`：状态条存在且正文 ≥12 px；空状态文案命中；空格/←/→ 改变帧号。
- 性能：统计标注页可见/不可见时的 `setFrame` 次数（`frameCopies` 已有计数器可扩展），改前改后对比。
- 视觉：同一会话、同一帧的 before/after 截图并排存证。
