## 设计决策（不一致已澄清）

- **`frame_rate_hz_measured` 不落**：板上 3 个真实 meta 都没有这字段；replay `default_fps` 已有"缺省回退 10"路径。剪辑沿用此，不造剪辑特有键（契约最小面）。
- **`topics` / `topic_message_counts` / `total_dropped_points` 不落**：剪辑只切点云帧，IMU/状态 684/29 条切不了，落虚假字段会伤下游消费者。
- **`extraction` 全重写**：`tool=human_replay_trim/0.1`、`source_session`、`source_range=[s_seq,e_seq]`、`source_tool`；不带 `source_bag*`（剪辑后失真）。
- **新 sid**：`<src_sid>_clip_<s_seq>-<e_seq>`（用户可凭 seq 反查回源会话的帧位置，HR-05 标注绑定契约要求）。
- **UI 不落盘**：浏览器只生成 `node trim.js ...` 字符串并复制到剪贴板；唯一权威切片由 CLI 承担。`textarea` 兜底手动 Ctrl+C。
- **大文件不全量读**：40MB 源走 `fs.createReadStream({start,end-1}).pipe(...)`，零驻留。
