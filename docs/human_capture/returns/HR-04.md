## 设计决策

- **相机切换**：透视 ↔ 正交换 S.camera，TrackballControls.object 重绑；S.cam_persp 保持引用以便切回时不重建（Trackball 跟 controls.object 是引用关系，切回就是写回原 cam）。
- **正交视野**：固定 `ORTHO_HALF_W=10`、`ORTHO_HALF_H=7`（20×14m 视口），resize 时按屏幕纵横比调 half_h 保宽。
- **视图预设语义**：7=top（相机 z=15 空中俯瞰 x 上屏）、1=front（人眼高 1.5m 驾驶视角，x 前向）、3=side（雷达右侧向左看，y 上屏）、0/home 复位到 VIEW_RESET。README §5Home 归位同义。
- **坐标读数（R3）**：mousemove 无节流，把光标逆投影到 z=0 平面；O(1) 无开销；不扫点云。
- **P 快照（R4）**：按下 P 时扫当前帧（~50k 点 5ms），x-y 平面欧氏最近；快照 HUD 显 `(x,y,z,i)` + 距光标距离 + 黄球高亮（复用单例 marker）。
- **M 标尺（R5）** 三态机：无尺→定 p1→定 p2 出尺→再按 M 清仓。标尺用红色 Line + 端球 + canvas texture Sprite 标签。
- **菜单与 localStorage**：aux (grid/grid_fine/axes/origin) + refs (person_stand/person_lying/door_21/door_17) 各 4 个 checkbox，独立开关，状态写 `localStorage["human_replay.<key>"]`，加载时恢复。
- **人形拖拽**：standing person 专属（README §5「1.8m 站立人形（可拖摆位）」），左键 mousedown raycast 到 → 锁 controls → mousemove 跟踪 floor 投影 → mouseup 释放。lying/door 无可拖需求，不实现。
- **飞行态屏蔽新键**：7/1/3/0/Home/P/M 在 `S.fly.on` 时不启用，语义错位（飞行中做 ground-level 量测没有意义）。

## 已知限制 / 未做（YAGNI）

- 正交模式下 TrackballControls 的 zoom 行为未调（Three 对 OrthoCamera 用 camera.zoom 而非距离缩——v1 不做同步，用户切回透视再缩）。
- 视图预设切换后 controls.target 保保留，正交 fov 无意义。无 viewport 拖拽，缩放靠切回透视 + 轨道滚轮。
- 标尺/人形位置不进 localStorage（HR-05 view_state 一并做草稿化，本单不必单独）。
- 参照物 lying/door 不可拖、不可旋转（README §5 图例没要求；HR-05 gizmo 统一管）。
- snap marker 生命周期跟 P 键走，切帧不清——**有意**（用户切片前后帧对比时标记仍在）。
- 无 viewport 精细投影自适（正交宽高比按屏幕实时调，没做锁定纵横比）。
