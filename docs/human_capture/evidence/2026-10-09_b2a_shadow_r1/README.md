## 4. 根因判定（裁定制式）

1. **柜位"闪框"主因 = 检测侧间歇成簇**（成簇率 22–24%、run 中位 1 帧）。背景差分 + 5 cm 漫水在柜面这类"亮面均匀、热点集中边角"目标上不稳定。
2. **id 漂移 (#2→#3→#4→#5) = "未成簇 gap ≥ TTL" 击穿**：gap 9–72 帧 > TTL 15 帧 → 旧 track splice → 复活新 id。RF 阈值全程未参与（柜位 prob 无 1 帧 <0.55）。
3. **截图 `track #8/#11` = 跨会话 uid 累计**：`HUMAN_DETECT_OVERLAY.last` 模块级常驻，多会话连放时 t_id_next 单调涨。显示缺陷，非追踪失败。
4. **阈值 Shadow 结论：无操作窗**。柜位 prob 0.76–0.87 紧贴真人 0.94–0.95，任何 ≥0.80 阈值都以真人为代价。证实裁定 C（难负样本进训练）是唯一正道。
