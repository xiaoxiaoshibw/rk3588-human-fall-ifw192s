## 0. 先回答问题：R3.5 "Registration attribution" 是不是 classifier 定义导致？

**不是。逐点迁移矩阵证明 registration bucket 随 transform 修正真实消解，不是标签假象：**

以 WD02 为例（159,247 个 online residual 点）：

| 迁移（A→B，逐点） | 计数 | 说明 |
|---|---:|---|
| `REG_GAP → ABSORB` | **95,709** | A 下"仅更好配准可吸收"的点，**98.8% 被 B 真实吸收**（不是转成 geometry/missing） |
| `REG_GAP → REG_GAP` | 1,142 | B 仍不够、C 才够（1.2%） |
| `GEOM → ABSORB` | 330 | A 瞬时几何近失，配准后吸收 |
| `MISSING → ABSORB` | 177 | 同上 |
| `SPARSE → ABSORB` | 595 | 同上 |
| `ABSORB → REG_GAP / GEOM / MISSING / SPARSE` | 1,345 / 2,023 / 293 / 33 | B 相对 A 的**损失**（共 3,694）——净收益 93,117 |

- A 条件下的 `MATCHER_GEOMETRY` bucket（53,799，占 WD02 33.8%）里，绝大多数在 state 语义下是 `REG_GAP`（即 A 的"几何失败"标签主要是错位把点推过 0.12 门形成的 shell），B 后仅剩 8,792（5.5%）真几何；C 后 8,222（5.2%）。
- A 条件下 `SPARSE_GATE` 38,458 → B 1,719：这些点在错位下找不到 ref 覆盖，配准后直接被吸收。
→ **结论**：R3.5 的 60.8% registration 份额是真实的 causal error（98.8% 可被一个独立固定的 ICP 消解），不是分类口径造成。

## 5. C 的 registration QA 与盆地敏感性（如实登记）

- C 主解（identity 初值）：ZYX euler (roll −2.3102°, pitch +0.0813°, yaw +2.2269°)，t = (−0.0064, −0.0288, −0.0099) m；**从 B 初值收敛到同一解**（逐位相同）；even/odd 对半拟合均收敛回同盆地（roll −2.30/−2.18）。预研复现 CHECK PASS。
- C_ALT（tls 初值盆地）：(roll −2.3373°, pitch +0.5931°, yaw +2.2435°)，t=(−0.0203,−0.0298,+0.0056)；**偶数半集拟合时该盆地漂移（pitch 0.593→0.712），是不稳定的浅盆地**——主解取其目标值更优（正常残差 p50 11.0 mm vs 11.7 mm）。
- normal-residual（全部静态细点，p50/p90）：A 38.8/119.7 mm → TLS 29.9/98.5 → **B 14.5/57.3 → C 11.0/56.6** mm；held-out（even→odd）C p50 11.1 mm。
- 敏感性结论：C 与 C_ALT 的 S1（WD02 相对下降 89.9% vs 85.9%）与 S6（人体高带 +0.5–0.6 pp vs 类似）**同向且都过门**；差异只在程度（C_ALT 对 WD01/WD02 的额外增益略低、对 NON_STATIC 吸收略高），不翻转因果结论。
- 限制：roll↔yaw/pitch 弱可观测 → C 不是数学上唯一全局最优；本报告以"independent 静态结构高置信对齐 + 双盆地敏感性"作为 oracle-like 上限的证据，不宣称 GT。
