4. HEAD=头、PELVIS_REGION=骨盆区域、LOWER_REGION=下部；LOWER_A/B只用于确实可分离的两组下部支撑。看不到用INVISIBLE，看不准用UNCERTAIN，写理由，不猜位置。确认真实头区域时才使用HEAD_CONFIRMED；不把最高点直接当头。
