# C1.5 采集执行表 (P0+P1, 采集当天照表执行)

> 2026-10-10。版本 v1。执行前提: 用户另行授权采集; 本表只是工单。
> 目标: 一把解决动态 GT 样本量 (n≥3 会话级统计) + 硬门距离衰减曲线。
> 采集链路: 板端 human_capture (HC-01..04) 录制 → HR-01 fetch 回 PC → 带刻度渲染 → 标注。

## 0. 批次规则 (每批次必做, 缺则数据半废)

1. **开工先录空场模板** E0 (无人 30s), 收工再录一次 E1 — 同一摆位/光照; bg_envelope 依它为基准。
2. **每段开头口播打板**: "段号-场景-距离-动作-开始", 结束口播 "段号-结束"。
   例: "D03 走停走 两米五 开始" → … → "D03 结束"。口播时间写入记录表。
3. 每段 20-60s; 雷达不动; 演员每次从画面外入场 (测 time-to-detect)。
4. 记录表 (纸上/手机): 段号 | 场景 | 距离 | 演员 | 路径 | 动作起止秒 | 备注。
5. **本批禁跌倒/危险动作**; P3 低姿态另行安排。
6. fetch 回 PC 后立即: `render_axis.py` 渲带刻度帧 → 抽检 3 帧确认画质OK → 再录下一批。

## 4. 标注 SOP (采集后, 不满足则只算 assist 级)

1. `render_axis.py` 渲全部帧 (带坐标刻度, 禁用旧无刻度渲染)。
2. AI triage 预筛 (categorical: present/activity) → 人工逐帧确认。
3. 坐标以刻度读数 + 与生产探针 track 锚定双源核对, 禁纯数格。
4. D01-D03 动态段: 关键帧双人独立标注, 不一致仲裁 → 才升级 `source:"human"`。
5. 不确定帧标 `uncertain` 不计分母。产出 `<sid>/gt_v1.json` (GT_SPEC.md §4 契约)。

## 5. 达标线 (本批完成后 C2 可行性复评)

- 动态独立会话 n≥3 (D01-D03 均自洽) → Wilson 可算;
- 距离衰减点 ≥4 档 (1.2/2.5/3/4/5m) → 硬门安全边界有数;
- GT 达 source:human 级 (双核) 至少 D01/D02。
- 未达标项照常标 BLOCKED, 不凑数。
