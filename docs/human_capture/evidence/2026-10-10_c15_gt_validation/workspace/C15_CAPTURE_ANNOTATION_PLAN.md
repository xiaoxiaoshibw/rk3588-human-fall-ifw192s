## 2. 采集方案 (待授权)

### 场景矩阵 (每场景 ≥3 段, ≥2 距离档, 20-60s/段)

| 编号 | 场景 | 关键变量 | 目的指标 |
|---|---|---|---|
| S1 | 空场 | 无人, 含家具 | FP/误检率 |
| S2 | 静立 | 近/中/远 3 档距 | 保留率、少点误杀 |
| S3 | 直线走 | 横向/纵向, 常速 | FN、time-to-detect |
| S4 | 走-停-走 | 多次起停 | fragmentation、recall |
| S5 | 转身 | 原地 90/180° | track 连续性 |
| S6 | 遮挡 | 走过柱/家具后重现 | ID switch、reentry |
| S7 | 远距 | 3/4/5m | 距离召回衰减、少点 |
| S8 | 静止保留 | 停 30-60s 不动 | still retention、TTL |
| S9 | 多人 | 2 人交叉/并排 | ID 分配 |
| S10 | 低姿态* | 坐/蹲/弯腰 (安全, 不跌倒) | z 带覆盖 (C2 前置) |

*S10 与跌倒为主线下游 (W06/W07), 本阶段只需"安全低姿态", 禁真摔。

### 采集规程
- 复用现有 human_capture 链路 (HC-01..04 板端录制 + HR-01 fetch)。
- 每段 meta 记录: 场景编号、演员、距离、路径草图、起止动作时间 (口播/打板)。
- 采集同时用 leveling + 时间戳, 保证帧率与 leveling 已知。
- **空场模板**每批次重录, 与动态段同一光照/摆位。

## 3. 标注方案 (source:"human")

- **渲染**: 一律用带坐标刻度渲染 (`render_axis.py` 或等效), 禁止无刻度图。
- **工具**: 沿用 film_person 逐帧 PNG + 顶/侧视; 坐标以渲染刻度为准, 必填到 0.1m。
- **流程**: AI triage 预筛 → 人工逐帧确认 (present/activity/top_xy/track-id) → 不确定帧标 `uncertain` (不计入分母)。
- **双人复核**: 动态段 (S4/S5/S6) 关键帧双人独立标注, 不一致仲裁。
- **产出**: `<sid>/gt_v1.json` 契约见 GT_SPEC.md §4; 保留原始渲染与 SHA。
- **防泄漏**: 标注集按会话划分 train/dev/holdout; 不调生产阈值。
