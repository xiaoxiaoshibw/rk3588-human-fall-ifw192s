## 用户观察核对（2026-10-08）：上方绿色团块 = 桌子，不是人

`probe_rescued_clusters.js` / `.log`（只读诊断，口径同上）。215540 每帧 v2 链共 3 簇，救回点形成 3 个团块：

| 团块位置（配准系） | n 点 | 链判定 | 离最近参考体素 | 结论 |
|---|---|---|---|---|
| (2.11, −0.52) z̄≈0.94 | ~1728–1764 | **HUMAN_CANDIDATE / CONFIRMED_HUMAN** | min=353mm | **人**（不在模板中，正确救回；3/5 确认） |
| (2.19, 1.25) z̄≈0.63 | ~1565–1591 | **NON_HUMAN / NON_HUMAN** | min=149–202mm / 中位 221mm | **桌子**（家具泄漏轨迹；v2 只保点，决策层判非人） |
| (1.26, 1.98) z̄≈0.57 | ~574–608 | **NON_HUMAN / NON_HUMAN** | min=48–73mm / 中位 149–180mm | 低矮物/边缘（同上） |

- 桌子为何被"救回"：它离模板最近体素还差 **15–22cm**——超过 0.12m 命中半径（该配对配准为 DEGRADED、inlier 0.46；且 5.5s 空场模板覆盖边缘）。v2 的 fail-safe 语义（宁可少删背景，不许吞人）使其保留为**候选点**，随即被聚类+几何门判 **NON_HUMAN**。
- 这正是 A/B 轮公开的「参考覆盖缺口泄漏」代价（非人 2.1–2.5k 点/帧）；本轮实测其中 ≈0.8k 落在人位裁剪区内（同一桌子团块）。
- 视图已按此事升级：模式②/③ 中救回点再按链判定分色（人=亮绿 / 几何候选=橙 / 链判非人=暗橄榄），桌子不再与人同色；
  人体圆柱内 215540 f0 全部救回点均落入"人通道"（1731/1731）。

### 追问核对（2026-10-08）：有参考，为何桌子没被参考层吸收？——`probe_desk_vs_ref.js` / `.log`

精确口径：桌子救回点（f0，在线命中且参考无支持） vs 233658 原始点（denoised，54 帧并集）与 occ≥0.5 体素。

| 量 | 数值 |
|---|---|
| 桌子救回点 | n=1619，形心 (2.195, 1.256, 0.610) |
| 模板原始点 r=0.45m 内 | n=21889（≈405 点/帧），形心 (2.043, 1.257, 0.767) → Δx≈−0.15m、Δz≈+0.16m |
| 桌子点→最近模板**原始点** | min 31mm、p10 120mm、**中位 251mm**、p90 ∞；≤12cm 仅 **10.0%**（≤25cm 49.8%） |
| 桌子点→最近**参考体素**形心 | min 120mm、p10 160mm、中位 267mm；≤12cm 0%（构造保证）、≤20cm 25.8% |
| 配准质量（215540→233658） | gate=**WARN(SPARSE_CORRESPONDENCE)**；n_corr 5946/12956、inlier 0.459；fit p50/p90=10/52mm；holdout p50 6.7mm；euler≈(−1.29°,−0.14°,−0.06°)、t≈(0.002,−0.028,−0.024) |

结论：**参考没有缺席、也没被绕过**（同区域模板点 405/帧；参考层在整个裁剪区每帧仍删 12934 点）。问题是这份 5.5s 模板与本会话在桌子处的**逐点对齐差 15–25cm**，远超 0.12m 命中半径——来源组合为 ① 跨会话配准为 DEGRADED（46% 静态对应点被剔、残差 p90≈5cm，局部错位更大）与 ② 5.5s 空场在桌面外沿覆盖/采样偏薄（occ≥0.5 体素尤甚）。按 v2 fail-safe 语义保留为点、由几何门判 NON_HUMAN；与 A/B 公开代价一致。**不改 0.12m 半径与 occ 门**；根治路径 = 正式空场 20–60s 采集（协议已备，等板端）+ 配准质量治理（W03/R3.9 线，另行授权）。

视图同期新增"空场模板原始点（233658 抽样 9:1，245759 点）"图层（默认开、可关；`v2_view_refpts.js` / `make_refpts_layer.js`），可与救回点同屏直看错位/缝隙。
