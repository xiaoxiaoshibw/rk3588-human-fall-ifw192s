## 0. 判定口径（必须随结果阅读）

- **标签（02 §3，互斥主因，判定顺序）**：`MATCHED_REF_ICP`（icp 下被参考图吸收）→ `XY_MATCH_Z_FAIL` / `Z_MATCH_XY_FAIL` / `DISTANCE_OVER_GATE`（±1 邻域有 occ≥0.5 体素但 d≥0.12，按轴向拆分）→ `REFERENCE_HOLE`（有 0<occ≤0.5 记录）→ `TIER_REJECT`（在线有 hits≥1 但无 tier 体素）→ `NO_REFERENCE_NEIGHBOR`（两套统计都没有）。`UNKNOWN` 用量 = 0。
- **bucket（矩阵列；与标签同源、互斥）**：
  - `REGISTRATION` = icp 命中且 none 未命中（配准决定性）；
  - `REFERENCE_ABSORB`（额外列）= 连 none 都命中（对配准不敏感，参考图/融合直接可消）；
  - `MATCHER_GEOMETRY` = 上述 1a/1b/1c 三标签；
  - `REFERENCE_MISSING` = `REFERENCE_HOLE` + `NO_REFERENCE_NEIGHBOR` + 低可见 `TIER_REJECT`（邻域 occ(≥1) max < 0.65）；
  - `SPARSE_GATE` = `TIER_REJECT` 且邻域 occ(≥1) max ≥ 0.65（可见性足够、被 ≥2 点/帧门排除的 M2 型）。
  - 每行 bucket 总和 = 100%（无重叠计数）；`reason_secondary[]` 只作附注、不参与统计。所有分组 `Other = 0`。
- **proxy（站点窗口专用）**：`STATIC_STATION` / `AMBIGUOUS` / `NON_STATIC` = 与「裸站点」旁观帧 {63,80,92,123}（受试者已离开站点）的残差点在 0.10 m 内吻合的帧数 ≥2 / =1 / =0（逐点计数，见 §2）。person 带 = z≥1.2（站点结构在裸帧顶部 ≤1.23 m）。
- **点级 vs voxel 级两套权重都必须看**：voxel 级先把每（帧,3D 体素）内的点归为一个主导 bucket；本数据点/体素密度极不均匀（全体 759,349 点 / 227,188 体素 ≈ 3.3 点/体素），少数致密点云会放大点级比例（工单 §九的提醒已在数据中兑现）。

## 2. 关键前提发现：站点窗口的"静态残块"与 reference 同构（**新证据，需用户复核**）

r6 与更早把 f10/f30 当作"纯静态错误族"（cl01：STATIC_RESIDUAL_CLUSTER；工作单 §七同口径）。本轮数据不支持该前提的"纯静态"部分：

1. **先验记录**：r3/10 时间线记载 "f1–62 受试者站在 (1.5,0.85)"（且 R3.3 的 known-static 排除盘就包含 (1.45,0.85) 这个"受试者活动驻点"）。
2. **时序列（站点窗口 r≤0.6，0.8≤z<1.3 点数，165 帧）**：f0–33 ≈1155–1167；f34–54 摆动 1010–1293；**f55–62 崩落** 1270→1235→924→682→481→251（受试者离站，trajectory 日志 f50–62 同步）；f65–142 稳定 ≈250；f143–153 回升 294→1353；f154–164 稳定 1400–1620（受试者回站）。
3. **裸站点佐证**：以受试者远离站点的 {63,80,92,123} 帧为"裸站点"参照（raw denoised 点、窗口 r≤0.65）——f10 的 0.8–1.3 带共 **1,204** 点，其中 **961 点（79.8%）在裸帧中没有对应（corrob=0）**，241 点 corrob≥2；而同帧低带（z<0.8，桌体）4,230 点中 corrob≥2 达 3,750（88.7%）——即"随人出现/消失"与"始终在场"在这两带之间分离得很干净。工具内（残差口径、窗口 0.6）f10 块点计 NON_STATIC = 937。
4. **跨会话比对（无对齐，同坐标系）：f10 块 ↔ REF f50 块 NN p50 = 0.026 m（78.5% <5 cm）**；REF 自身 f0↔f50 p50=0.011 m（91.9% <2 cm，完全静止）；f10块↔f63块 p50=0.243 m（不是遮挡，是结构改变）。→ 参考会话**存在同一位姿的同一物**。
5. **reference 污染度**：站点带（0.8≤z<1.3，occ≥0.5）50 体素、mean occ 0.935；f10 的 937 个 NON_STATIC 块点中 **288 个（30.7%）** 在 5 cm 内就有 ref 体素（none 口径）；icp 口径吸收 **931/937 = 99.4%**。

结论（proxy，non-GT）：站点窗口 0.8–1.3 m 的残块是与受试者"到站/离站"同步出现/消失的**可移动物或受试者本体**（逐点不可区分）；**参考图在该处复制了同一状态**。因此：
- f10/f30 的 66% "none 即可吸收"不能计为"静态泄漏被正确修复"；它是"**reference 含会话特定/可移动状态**"的实证（对 fusion 类方案是风险样本，对 f10/f30 的旧分类是修正信号）。
- 提议列为**待用户裁决项**（是否把 f10/f30 从"纯静态错误族"改登记为"站点混淆族"）。本轮不擅自改分类、不动 milestone。

## 3. GQ 回答

### GQ1 registration error 占多少？（残余静态漏检中，配准贡献）

| 组 | icp-only 命中（bucket Registration）点级 | none→icp 命中率 | 说明 |
|---|---:|---:|---|
| WD01 | 14.5% | 84.0% → 98.0% | 与 R3.2/ICP 复跑一致（+14pp） |
| WD02 远场 | **60.8%** | 34.2% → **92.7%** | 远场静态的第一大项 |
| ALL | 18.2%（voxel 级 42.8%） | 31.7% → 47.6% | voxel 级因稀疏碎片更凸显 |
| PROBLEM | 20.3% | 42.1% → 60.1% | — |
| CLEAN（人） | 15.4% | 15.5% → 29.1% | 与人体无关（人的点在 none/icp 下都不匹配） |

- tls（仅旋转直逆）单独贡献甚微：WD02 在 tls 下 27.2% < none 34.2%（无平移的 tls-direct 会把远场推得更差）；icp 的增益主要是平移+完整解。
- **答**：对**已知静态**（WD01/WD02），registration 占残余的 14.5% 与 60.8%，是远场的第一主因、WD01 的第二主因；对站点块（f10/f30）registration 无关（93% 在 none 下即可吸收，§2）。

### GQ2 reference missing / occupancy / sparse gate 占多少？

- **已知静态**（WD01/WD02）：`Reference missing` 0.3% / 0.7%，`Sparse gate` 0.01% / 1.1%——**参考图覆盖基本不缺**（配合 01 §6：5286 体素 / occ≥0.5=3707 复现通过）。
- `ALL` 的 `Reference missing 36.8%` 是 clean/近家具帧里的**人体点**（CLEAN 56.6%）——人体不被背景表示是**期望行为**，不是错误。
- **M1 vs M2 实点名**：站点块（f10/f30）在线视角 553/547 个 `TIER_REJECT` 点中，occ(≥1)<0.65 的 M1 型 531/534（可见性/在场受限），occ≥0.85 的 M2 稀疏型仅 2/2。→ 站点块不是"每帧 1 点被 ≥2 门杀掉"的 M2 型，而是"该物大多数帧根本不在那（可移动）/被遮挡"（M1 型分母/在场问题）。
- **答**：对测试集内的静态结构，reference missing/occupancy/sparse 是**小头**（≤1.1%）；ALL 的大比例是人体（应然）。M2 稀疏门在 WD02 上仅 1.1%（与 R3.1 "≥1 门回收 1632 候选体素"并不矛盾——回收发生在**reference builder**，而 production 仍未用 reference）。

### GQ3 纯 matcher geometry 占多少？

- 已知静态：WD01 **1.7%**、WD02 **5.5%**（voxel 5.7% / 5.8%）。
- 轴向拆分（icp 下超门点）：`Z_MATCH_XY_FAIL`（高度已贴合、平面超门）为主——WD01 1186/1581 (75%)、WD02 5084/8792 (58%)、ALL 51332/83582 (61%)；`XY_MATCH_Z_FAIL` 很少（28/967/6926）。
- **答**：参考图存在且配准合理时，纯 matcher geometry 的份额小（个位数%），且其中"高度分量几乎不失败"——问题几乎全部集中在**平面（XY）漂移**，这与 registration/sampling 的残余是同一现象在 0.12 门上的投影；不存在"改几何公式就能吃掉的独立大头"。

### GQ4 f155 / f160 是否集中在 d∈[0.12,0.24] shell？

- 窗口内"有 ref 体素但未命中"的点：f55 **70.3%**（792/1126）、f155 **60.5%**（877/1450）、f160 **83.4%**（771/924）落在 [0.12,0.24)——**shell 现象成立**。
- 但按 proxy 拆分（@icp）：f155 shell = 788 NON_STATIC / 25 STATIC_STATION / 64 AMBIG；f160 = 657 / 66 / 48；f55 = 718 / 12 / 62。**shell 主体是"紧贴参考体素的人体表面/可移动块"，不是静态结构边缘点**。
- **答**：GQ4 的"shell 存在"= YES；"shell ≈ 静态结构边界（可被 AABB/半径类 matcher 安全吃掉）"= **NO**。吸收 shell 的代价将主要落在人体边界点上（f155/f160 人体高带 retention 分别为 94.9% / 91.6%，若扩张吸收面还会下降）。本轮因此**未实现 AABB**（工单 §12）。

### GQ5 f10 / f30 是否支持"错误在 reference 构造阶段形成，而非 matcher"？

- **支持"非 matcher"**：站点块在线视角 553/547 个 `TIER_REJECT` + 384/391 个在线邻域超门（Z_MATCH_XY_FAIL 557/559 等）——在线 map 要么没收录（hits 不足 tier），要么收录的形心在门外；这与 R3.0 M1/M3 的在线侧机制同型。
- **支持"reference 阶段"但需改写主语**：该块在参考图下 93.3%（none）/99.4%（icp）可吸收——说明"背景模型缺这个状态"才是生产行为的成因；但参考图的覆盖是"复制了同一可移动状态"（§2），**不能被当成"静态泄漏被正确修掉"**。
- **答**：f10/f30 = "错误在背景/参考层形成（非 matcher）"成立；同时它们是"**reference 质量**"样本（含可移动状态），不是"纯静态"样本。

### GQ6 f55：静态恢复 vs 人体误吸收风险

- 人体带（z≥1.2）：n=**1248**，icp-center 吸收 **2（0.16%）**（none 口径 8/1038≈0.8%）→ 当前 center matcher 对人体高带**几乎无风险**。
- 混合带（0.3≤z<1.2，受试者下半身 + 站点块，逐点不可拆分）：n=**1467**，吸收 **775（52.8%）**——任何"吸收更多"的方案都会先吃掉这一带；其中低带（0.3–0.8）吸收 441/614≈71.8%（NON_STATIC 主体 439/567≈77%）。
- 真静态站点 proxy（corrob≥2）：仅 52 点（站点主体已被在线 map 吸收故不在 residual），吸收 5（9.6%，n 太小）。
- **答**：f55 的"静态恢复"数值小（站点真静态多数已在线吸收）；"人体风险"在 z≥1.2 极低（0.2%），但在 0.3–1.2 混合带已有 53% 吸收——**不能用"被 reference 吸收更多"作为改善指标**；r5 报告的 AABB 在 1.2–1.8 额外吸收 200 人体点的已知问题，在本轮 center+icp 口径下对应高带 2/1248，说明**风险集中在 matcher 扩张类方案**（本轮不实现）。

## 5. 计数与重叠口径（工单 §十）

- 矩阵 bucket 互斥，行和 100%；`reason_secondary[]`（CSV）记录同一点在其它视角/模式下的差异标签（如 `online=…`、`ref_none=…`），**不参与任何比例计算**，无重复计数。
- 点级 share = 点数比；voxel 级 share = 每（帧, 3D 体素）点计数主导 bucket 的体素数比（并列按固定顺序取先者：Ref absorb → Registration → Missing → Geometry → Sparse → Other，`UNKNOWN` 未出现）。
- 迁移矩阵（三档命中组合 000–111）在 JSON `transition_*`；ALL：000=49.6%、001=14.7%、011=3.5%、101=3.1%、111=26.3%、110=1.4%、100=0.9%、010=0.5%（非单调：reference 图案随配准改变，同一点可在 none 命中而 icp 不命中）。
- `d` 分位（icp 至最近 ref tier 体素）：matched p50 ≈0.058（ALL）/0.049（WD01）/0.061（WD02）；unmatched p50 ≈0.193/0.147/0.147——unmatched 集中在 shell 与 bulk 之间的 0.15–0.22 带，与 GQ4 的 shell 结论互证。

## 6. 局限（随结果阅读）

- proxy ≠ GT：所有"静态/人体/可移动"表述均为匹配或时间一致性代理；站点块无法逐点区分"椅/装置/受试者本体"。
- 单一会话对 + 单一 ION 路口径；ICP 解非唯一（登记于 R3.2）——GQ1 的 92.7%（WD02）是"固定 ICP 条件下"的参考量，不是可部署结论。
- 参考图仍为 10.5 s 候选（正式 20–60 s 空场未录，BLOCKED）；本轮新增的"reference 含站点可移动状态"进一步说明**正式空场录制时需明确站点无人/无物移动**。
- `POST_FILTER_ERROR`（显示层）不在本工具范围；retention 一律按簇/窗口 proxy 计量，不用显示颜色。
