## 1. 问题（已实测）

- 全程静立的人（4×6s，站/举手）被**在线自建模静态图**删除 97–98%（前景仅 14–57 点/帧，无 confirmed）。
- 根因：背景模板只认"占用率 ≥0.85"，没有身份/可见性语义——**6 秒不动的人 = 家具**（代码自述已知边界）。
- 下游没有错：几何门/确认链在残片上没有误判；"看不到人"发生在上游删点。

## 2. 目标与不回归项

- 目标：静立的人（含"从第 0 帧就静立"）保留为可见候选/轨道。
- 不回归：WD01/WD02 静态泄漏仍被清除；空场固定物 0 candidate / 0 confirmed；**不改 0.65/0.85 占用阈值、不改聚类/资格门、不改 T38 共同门语义**；console leveled 为唯一验收口径。
- 生产接入另审：本计划只做离线诊断与设计，R3.9 一类接入需单独授权。
