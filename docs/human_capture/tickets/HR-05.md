## 范围（做什么）

### 浏览器（replay.js + index.html 增量）

- **B/V 模式键**：HUD 常显当前模式；B=框选（左键在地面拖矩形）、V=查看（左键轨道旋转）。默认 V。
- **顶视正交画框**：B 模式下左键拖 z=0 地面，z 自动取 2%/98% 分位；松手落一个未定稿框（wireframe 红）+ 默认选中。
- **W/R/T gizmo 模式切换**：translate/rotate/scale；按钮 + 键位同步。
- **轴约束**：按住 X/Y/Z → 对应轴锁定；轴约束态在 HUD 常显。
- **捕捉**：按住 Ctrl → 移 0.1m / 旋 5°(π/36) / 缩 0.05。
- **数值面板**：选中框后右下面板展示 center/size/yaw/label/id；双向绑定：面板改 → 几何+gizmo 立即更新；gizmo 拖动 → 面板数字同步。NaN / 负 size / 超 ±100m 拒绝并恢复原值。
- **Ctrl+Z/C/V**：20 层 undo 栈（add/del/edit 均可撤）；复制 Ctrl+C 快照 label+size+yaw；粘贴 Ctrl+V 到当前 frame，新 id。
- **Enter 定稿**：box 锁定为已定稿（颜色变更 + gizmo 脱离）；再 Enter no-op。
- **Del 删除**：window.confirm 防误；删除进 undo 栈。
- **Esc 逐级退出**：1 = 摘 gizmo；2 = 取消选择；3 = 退出 B 模式到 V。归一入口。
- **本地持久化（草稿）**：`localStorage["human_replay.annotations.<sid>"] = {frames: {seq: [box,...]}}`，切帧 / 切 view / 切会话全部自动保存 + 恢复（HR-04 ls_get_raw 语义的字符串版 JSON）。
- **切帧守卫**：当前帧有未定稿框 → confirm「未保存，确定离开？」；确认则丢弃草稿，否则留在当前帧。

### `human_replay_lib.js` 追加纯函数

```
bbox_from_ground_rect(p0, p1, points) → {center, size, yaw:0}
    p0/p1 = z=0 平面两对角（[x,y] 或 [x,y,0]）；points = 当前帧 Float32Array 或 null
    z 高度 = points 在 [p0,p1] 内 z 的 2%/98% 分位，null → 默认 (0, 1.8)

bbox_from_rect(p0, p1, zmin, zmax) → {center, size, yaw:0}
    上面兜底版：无 points 或空时使用

undo_stack_new() → {stack:[], capacity:20}
undo_stack_push(st, entry) → 返回新栈（容量关键，第 21 条推入时第 1 条 shift 出去）
undo_stack_pop(st) → {entry | null, new_stack}

annotation_serialize(annotations_by_frame, session_meta) → {annotations: [...]}
    按 meta.frames[].seq 顺序拼接所有已定稿框，每个字段对齐 README §2 契约；
    返回 object 供 fetch body 直接 JSON.stringify。

annotation_validate_box(box) → true | string 理由
    center/size 是三维有限数；size.x/y/z > 0 且 ≤20m；center.x/y/z ∈ [-100, 100]；
    yaw 有限且 ∈ (-π, π]。

annotation_snap_step(mode, value, ctrl) → number
    mode ∈ {"move","rotate","scale"}；ctrl=true 时取步长 0.1 / (π/36) / 0.05 的整数倍。
```

### `human_replay_lib.py` 追加 `/api/save_annotations` POST

- Body = `{sid: "cap_...", annotations: [...]}`（annotations 直接是 README §2 契约数组）。
- Sid 校验：`^cap_[0-9_]+$`。
- 加载 `<sid>/meta.json`，原子步骤：
  1. 校验所有 11 个冻结字段：`format / format_version / session_id / sensor / time_domain / duration_sec / frame_rate_hz_measured / topics / point_layout / point_file / frames / extraction` 与内存中原值**逐字段相等**（deep equal）→ 任一变更 fail；不覆写其他字段。
  2. 覆写 `human_annotations` = body.annotations。
  3. 写 `<sid>/meta.json.tmp` → flush → os.replace 到 meta.json（Windows 上即 rename 语义）。
  4. 对结果重新 sha256 一次，把 sha 记进日志（不回写文件——sha 不是契约字段）。
- 失败任何一步：尝试 restore；恢复失败则把旧 meta.json 保留在 meta.json.bak，然后报 fail。
- 幂等：同样 body 重复送 → 同样 meta.json（无时间戳等随机字段）。
- 返回 `{ok: true, count: N, sha256: "..."}` 或 `{ok: false, error: "..."}`。

- **不做跨帧插值**（隔开 N 帧自动复制框），不做旋转框（仅 yaw，无 roll/pitch），不做自动标注模型。
- **不动 HR-01..04 已有函数语义**：`apply_view_preset / ls_get_raw / view_preset / measure_* / aux_* / ref_* / fly_* / trim_panel_*` 一律保持。
- **不改 vendor three.min.js / OrbitControls / TrackballControls**；TC 只做 mount/dismount，不对它打补丁。
- **不改 human_annotations 字段定义**，不新增 `source` 之外的判别字段。
- **不动 frames / extraction / points.bin / point_layout / sensor / topics / point_file / duration_sec / frame_rate_hz_measured / time_domain / format / format_version**；save 接口碰到这些字段被改直接 fail。
- **不开新端口**；8901 接 `/api/save_annotations`。
- **不 commit / push**；工作树允许脏。
