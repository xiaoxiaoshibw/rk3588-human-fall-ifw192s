# HR-02 — PC 回放器：meta+points.bin 加载、Three.js 渲染、播放/逐帧/时间轴

> 位置：`pc_apps/human_replay/`（HR-01 已在此落 fetch.py/config.py）。
> 数据源：`D:\Code\ldiar\captures\remote\<sid>\{meta.json,points.bin}`（HR-01 产物，D1 路径）。
> 渲染：Three.js r128（**与 webui/ 现有副本同源**，README 写 r127 属笔误，以仓内 r128 为准）+ OrbitControls，vendor 进仓零外网。

## 背景事实（HR-01 落地时核实）

- 板上 meta.json 真实契约：`point_stride_bytes=28`，fields=[x,y,z,intensity,ring,timestamp]，pad@18/24。README §2 的 16B 描述滞后，本单纯消费不解剖布局。
- `frames[i].offset_points/count_points` 是点索引，字节偏移 = ×28。
- 仓内 three 副本在 `webui/three.min.js`（r128）+ `webui/OrbitControls.js`，全页通用、已验证。本单把它俩 vendor 进 `pc_apps/human_replay/vendor/`，与板端仓解耦（PC 侧离线可用，HR-05 的 TransformControls 同位补）。
- 时间轴基准取 `frames[i].bag_time_sec`（bag 落盘墙钟，单调连续）；`stamp_sec/stamp_nanosec` 是雷达上电秒、跨年不锚定，只显示不导航。

## 范围（做什么）

- `vendor/three.min.js`、`vendor/OrbitControls.js`（拷贝自 webui/）。
- `human_replay_lib.js`（node 可测纯函数层，DOM/THREE 零依赖）：
  - `strided_f32_copy(buf, base, count, stride_items)`：从跨步缓冲抽稠密 f32 段
  - `frame_slice(meta)`：帧索引→[start,end) 点区间表（含累计校验）
  - `pick_intensity_range(...)`：2%/98% 分位（与 D9 的 z 分位同源做法）
  - `format_hhmmss(sec)`、`playback_speeds`
- `index.html` + `replay.js`（浏览器层，仅此层 import THREE）：
  - 打开页 → 选 `<sid>` 目录（webkitdirectory）→ 载入 meta.json/points.bin
  - 渲染循环：`requestAnimationFrame`，按目标 fps 推进帧号；默认速度 = `frame_rate_hz_measured`，可切 0.25/0.5/1/2/4×
  - 点云 = 一个 `THREE.Points` + 预分配全量 `BufferGeometry`；切帧只动 `drawRange`（零每帧分配）
  - 着色：按 intensity 灰度（PointsMaterial + 归一化到 2%/98% 分位窗口）
  - 控制：空格播放/暂停、←→ 步进（Shift×10）、速度档、循环、时间轴拖动/点击、HUD 常驻 `seq/bag_time/点数/idx`
  - 雷达原点小标记 + Y-up/Z-forward（与板面预览同系）
- `human_replay_lib.test.js`：node 跑，覆盖 strided copy、分位、帧表、时间格式、速度档。

## 不做什么（防漂移）

- 不编辑/剪辑/另存（HR-03）；不画框、gizmo、双相机、四视图（HR-04/05）。
- 不写回 meta.json任何字段；回放器对产物**只读**。
- 不做感知/聚类/落盘日志；后端零逻辑（静态文件，`python -m http.server` 即可）。
- 不做 intensity→伪彩 LUT 切换（灰度一档够看；要彩再说）。

## 实现基线（ponytail）

- 单 `THREE.Points` + drawRange，`setDrawRange(start,count)` O(1) 切帧。
- intensity 归一化在**加载时算一次**（分位窗口），切帧不动颜色。
- 全量 bin 一次读完（40MB 级会话 <1s），不流式不分片。
- 选目录用 `<input webkitdirectory>` 原生件，零依赖、Edge/Chrome 直接可点。
