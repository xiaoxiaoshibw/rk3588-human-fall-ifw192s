## 2. 分析（判断）

1. **最该立刻修的短板是 S-A 的循环性**（阈值在同一批样本上校准、样本手选、单人）。不修，后续一切阈值/结论都不可信；修它完全离线，不需要任何授权。
2. **保留修复与语义层是组合关系**：保留层（融合 v2 / 模板路线）决定"静立新人"能不能活到分类层；语义层决定活下来的是人还是物。二者都必要，但**离线验证互不阻塞**——语义层可先用既有样本做强，融合 v2 的收益/代价可离线量化。
3. **真正需要外部输入的只有两处**：多姿态/多人物采集授权（数据）、最终生产接入决策（授权+独立复审）。其余（选样、校准、A/B、冻结版本）我应自己完成。
4. **空场/负样本应从数据驱动产生**（按聚类大小/高度分层扫描），不再手挑——这同时是 P1 的方法论核心。
