## 1. 目标（按优先级）

| 编号 | 目的 | 最小内容 |
|---|---|---|
| C1 | 静立人保留实测（融合 v2 的受益集） | "走进→站定 8–10s"×3（不同站位：空处 / 贴箱子前 / 贴墙） |

## 2. 录制要求

- 同一房间、同一安装；每段 8–30s（C5 20–60s）；帧率/话题与既有会话一致（板端采集链路不变）。
- 每段一个动作、开头/结尾各留 1–2s 静止；同一动作重复 ≥2 次（跨段重复一次更好）。
- 现场记录：日期/站位（相对箱堆或地面标记，俯视草图即可）/动作说明/谁在做（代号）/异常（门开合、物品挪动）。
- 命名沿用 `cap_YYYYMMDD_HHMMSS`；录完走既有拉取→配平→配准流程（本轮工具已备）。

## 3. 标注口径（先"人还是物"，不标关节）

- 帧级 + 簇级标签：`PERSON / STATIC_OBJECT / MIXED / UNKNOWN`（看不清允许 UNKNOWN，禁止猜）。
- 姿态标签（C3）：`STAND / BEND / CROUCH_OR_SIT / LIE / TRANSITION`，仅标可见帧段。
- 事件时刻（C2/C3）：起身/躺下起始与结束帧；遮挡起止帧。
- 连续性（可选）：同一人的 person_id 跨帧链接（用于 W04 身份连续性）。
- 标注人署名；写派生文件，不改原会话（沿用既有 GT 纪律）。

## 4. 验收用途映射

- C1 → 融合 v2 A/B 受益集；C2 → 共同门（REFERENCE_STATIC > ONLINE_PERSISTENCE）实测；
- C3 → 语义层 H02/H06/H07 与 W05/W06 输入；C4 → H04 遮挡纪律；C5 → 参考模板与空场 0/0；C6 → 距离泛化。
- 未录到的项在验收表保持 NOT_RUN/BLOCKED，不用合成替代（数学冒烟除外）。
