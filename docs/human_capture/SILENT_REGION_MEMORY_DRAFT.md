## 3. L1 SILENT_REGION 定义

### 3.1 建区（以"簇"为证据单元，非"帧"为单元）

- 一个网格 cell（5 cm，与 bg_envelope 同 key）进入 L1 的条件（**全部满足**）：
  1. 该 cell 在 L0 参考层**命中**（r1 已证：柜位 prob 高但 cell 在空场包络内 → 参考层可查）；
  2. 最近 N=600 帧（60 s@10 Hz）内该 cell 被前景热点命中的帧数 / 热点总帧数 ≥ 0.85（占用率语义，沿用 R3.1 口径）；
  3. 该 cell 不属于任何 `age≥3 且 mean_prob≥0.5` 的 HUMAN_TRACK 的 90% 质心半径（r90）覆盖区——**人轨保护罩**。
- 进入 L1 后语义 = "此 cell 视同参考静态"，**唯一作用**是 `find_hot` 里被当作已解释背景（热点判定 `z > max(bg_l0, l1_z) + 0.25`）。

### 3.2 与旧"静止拉黑"的三处本质差异

| | 旧规则（废止） | 本草案 L1 |
|---|---|---|
| 证据 | 质心不动 N 秒 | **cell 占用率 ≥0.85**（密度语义，不是"懂不懂"语义）|
| 作用面 | 拉黑整条 track（人级） | 只抑制热点（点级），track 生死仍在 associate |
| 人保护 | 无 | 条件 3 人轨保护罩 + 后述退出条款 |

关键区别：静立人的点**只有遇到 L0 参考层命中的人轨保护罩内 cell 才会被 L1 吞**，而真人站立位置的 cell 恰好在**从 0 帧起就被 HUMAN_TRACK #1（mean_prob 0.95）覆盖**——条件 3 恒不满足 → L1 永远建不起来。柜子位置在 r1 里有四条 `mean_prob 0.84` 的 track（#2/#3/#4/#5），**罩不罩得住？**——见 §4 的防滥用条款。

### 4. 防滥用条款（针对"柜子也拿了高 prob track"）

条件 3 的保护罩资格**收紧为人轨 + 连续性双条件**：

> 保护罩 = `age≥3 且 mean_prob≥0.5 且 最近 150 帧 assoc 率 ≥ 30%` 的 track 的 r90 覆盖区。

- 真人（6 段实测 assoc 率 98–100%）恒满足 → 保护恒在。
- 柜位间歇 track（女中 19/107=18%、女近 33/218=15%）**不满足 30% 连续性** → 罩自动失效 → 该位置 cell 满足条件 1+2 时可入 L1 → 柜点被压回背景。
- 男中段柜位 #2（assoc 126/139=91%）会被罩——这是**故意的保守**：宁可让稳定柜位继续当人检预算内的无害 track（0.55 档它确实一直在 HUD 里），也不在 C（难负样本）落地前引入"能杀死真人候选"的新通道。

### 4.2 退出条款（人回来的可逆性）

L1 cell 出现以下任一情况即退出（与 R3.1 在线占用率滑动窗同构）：

- 近 600 帧占用率 < 0.70（人走进柜位、柜门打开）；
- 被 HUMAN_TRACK 保护罩重新覆盖 ≥30 帧。

退出后按普通背景处理，无黑名单记忆残留。
