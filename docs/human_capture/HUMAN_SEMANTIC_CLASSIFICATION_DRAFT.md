## 0. 一句话

在"点还在"（保留层）之后，用**聚类实例 + 短时序的结构剖面**回答"这是不是人"：识别头/颈/躯干/腿/上肢等**有点云支撑**的结构证据，输出 **人 / 非人 / 不确定**——结构证据是必要不充分条件；没有证据 ≠ 非人（是 UNKNOWN）；禁止无点补全；"拟合出骨架"不得当作"是人"的证据。

## 1. 原则（先立规矩）

1. **必要不充分**：`HUMAN` 需要结构正证据；无正证据 ⇒ `UNKNOWN`（不是 NON_HUMAN）。
2. **不无中生有**：看不到头/脚/关节 ⇒ invalid/UNKNOWN；不按身高比例补；家具也能拟合骨架，骨架不是证明。
3. **负证据独立**：家具特征（均匀厚板/宽平顶/强平面）给 `OBJECT` 侧证据；正负冲突 ⇒ UNKNOWN。
4. **轴向感知**：带化/分节沿**身体主轴**（直立≈世界 z；upcos 低 ⇒ PCA 主轴；卧姿 ⇒ 主轴水平）。
5. **可解释**：每条输出带数值证据与原因码（点数不足/遮挡/冲突/姿态不支持）。
6. **身份与结构分离**：本层只影响"资格票"与结构标志；**不取消 track 身份**（跨姿态保持、遮挡限时、含糊回 UNKNOWN）。
7. **可校准但防过拟合**：本层允许自己的新参数，但必须在多场景负样本上校准后冻结版本；不得回写保留/融合层阈值。

## 2. 管线位置与接口

- 输入：保留层输出的候选簇（体素/点集）+ 短窗（建议最近 10–20 帧）逐帧统计；坐标系 = leveled（地面 z=0）。
- 输出（挂到簇记录，替代/扩展 `evidence_label` + `joint_status`）：
  `semantic: HUMAN_EVIDENCE | OBJECT_EVIDENCE | UNKNOWN`
  + 结构标志 `{HEAD, NECK, TORSO, LEGS, ARM, FLAT_TOP, SLAB}`（各 `true/false/unknown`）
  + 数值证据 + 原因码。
- 消费：Tracker 3/5 票源改由本层输出（票 = HUMAN_EVIDENCE）；W05 结构节点（头/躯干/骨盆/腿）复用本层带剖面；W06 姿态使用主轴+剖面。
- 与现有 classify/joint 的关系：硬门与 spread_cv/aniso 降级为本层的**特征组之一**，不再单独裁决；先并存诊断，切换另评。

## 3. 特征集（沿身体轴的 10cm 带剖面）

- **F1 带剖面**：每带 `{n, 横向σx, 纵深σy, 带形心}`；覆盖 = 有点的带比例（可见性）。
- **F2 头/颈**：顶部 20–25cm 紧凑团（maxσ 小）+ 自下而上的收窄段（颈肩过渡）。
- **F3 躯干/腿**：中带（0.7–1.4m）宽度量级与**剖面 cv**；下带（0.15–0.6m）双柱（分离 d + **柱内σ**）或单柱窄腿。
- **F4 上肢**：头高以上小团（σ 小）且相对体柱横向偏置大（举臂）；肩高横伸（平举）。
- **F5 家具负证据**：剖面 cv≈0 的均匀厚板（SLAB）；宽平顶（FLAT_TOP）；强平面（aniso，沿用）。
- **F6 微动（短窗，待量）**：带形心微动独立度（人=非刚性微动；家具=刚性）；四段可先量，暂不参与判定。

探针实测（多帧合并；人=120k/127k 点、WD01=189k、箱=23k）：

| 指标 | 人(站 215540) | 人(举臂 215607) | WD01 家具 | 箱子堆 |
|---|---|---|---|---|
| 躯干带 spread (σx,σy) | 0.08/0.17 | 0.08/0.14 | **0.22/0.32** | 0.28/0.09 |
| sy 剖面 cv(0.2–1.2) | 0.11 渐变 | 0.10 | **0.02 均匀** | 0.33 不规则 |
| 腿双柱 d / 柱内σ | 0.28 / **0.07** | 0.20 / 0.07 | 0.68 / **0.15** | 0.23 / 0.11 |
| 顶 0.25m spread | 0.07/0.07 紧凑 | 手 0.06/0.04 | 0.08/0.15 一轴宽 | **0.26/0.16 宽顶** |

教训：朴素"颈/头宽度比"不可用（人 0.93 vs WD01 0.88，被肩带污染）；必须用**组合特征**。

## 4. 判定组合（草案；阈值为占位，待多场景校准）

```
HEAD    := 顶部带群 maxσ ≤ h_hdr(占位0.10m) 且 存在自顶向下收窄段
LEGS    := 下带双柱 d ∈ [0.08,0.40] 且 柱内σ ≤ l_col(0.10)；或 单柱 σ ≤ l_col
TORSO   := w_min(0.06) ≤ 中带宽度 ≤ w_max(0.30) 且 剖面 cv ≥ c_min(0.05)
ARM     := 头高以上小团 σ ≤ a_hdr(0.08) 且 偏置 ≥ o_arm(0.25)
SLAB    := 剖面 cv ≤ c_slab(0.03) 且 中带宽度 ≥ w_slab(0.25)
FLAT_TOP:= 顶带 maxσ ≥ t_wide(0.15)

HUMAN_EVIDENCE  := (HEAD ∧ TORSO) ∨ (LEGS ∧ TORSO ∧ ¬SLAB ∧ ¬FLAT_TOP)
OBJECT_EVIDENCE := (SLAB ∨ FLAT_TOP) ∧ ¬HEAD ∧ ¬ARM
UNKNOWN         := 其余（点数不足/可见带不足/证据冲突/姿态不支持）
```

- 举臂：ARM=true 提升 HUMAN 证据等级，但不单独定人。
- 遮挡：可见带 <3 或关键带缺失 ⇒ UNKNOWN（不猜）。
- 时序：窗内 ≥3/5 帧 HUMAN_EVIDENCE → 票；OBJECT 票**不能取消身份**（身份在 track，结构证据逐帧更新）。

## 5. 多姿态（轴感知）

- **直立**：如上。
- **弯腰**：主轴近竖直但头部下移、上带收窄；需真实数据校准（HP02 BLOCKED）。
- **坐/蹲**：高度 <1.2m、腿带短缩/消失、脚簇贴地；与矮家具冲突大 ⇒ 依赖采集数据。
- **卧**：主轴水平，带化沿主轴，头=端部紧凑团；旧世界 z 带化失效——本层显式支持。
- 合成数据只做数学冒烟，不作真伪结论（沿用纪律）。
