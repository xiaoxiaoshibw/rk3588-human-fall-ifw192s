# 地面识别与坐标配平：资料调研及方法审查

日期：2026-10-01。范围：公开一手资料调研、当前项目静态检查、方案选择和开发前关卡。本轮未运行开发 CLI、未安装库、未采集或操作板端、未修改算法及服务。项目中的旧实测数据仅作历史证据，未在本轮复测。

## 1. 推荐结论及适用前提

推荐第一版采用：**人工确认地面采样区域 + 有方向/安装高度先验的 RANSAC 候选平面 + 内点 SVD 精修 + 独立帧/区域验证 + 显式局部地面坐标变换**。

固定安装时完成一次标定并冻结变换；运行中只监测可信地面支持和标定状态，不逐帧改坐标轴。在线地面点分类使用已标定平面的有符号距离，并保留靠近地面的人体点证据。

这是针对当前“固定室内、预期平整场地、无有效姿态输入、已有 NumPy 几何代码”的工程选择，不是已在 IFW192S/RK3588 上验证的性能结论。真实地面不可见、多个地面高度或大坡面存在时，应重新审查单平面前提，不能靠改阈值强行通过。

“配平”对齐的是场地地面法向；如果场地本身有坡度，这不自动等于重力竖直。局部 ground_local 不等于地图/底盘外参或地理大地坐标。

## 3. 当前代码审查发现

### 3.1 最大平面先胜出，再检查方向

`src/human_fall_detection/core/ground.py` 的 fit_ground_plane 目前：随机三点 → 按全部拟合点支持数选一个最优平面 → SVD 精修 → 检查 normal_up_min_z。

因此墙占多数时可能先赢得模型竞争，随后被判方向不符，流程就退出；并不会因此回头找到支持较少的真实地面。该实现能避免部分假成功，但在地面存在时仍可能失败。

拟采用约束在候选阶段过滤明显不可能的平面，并在固定迭代预算内保留少量有空间支持的候选供质量核验。只有一个可辨认地面候选时才采用；桌面与地面仍有歧义时要求现场/ROI 证据，不把自动排名当物理真值。

### 3.2 源 Z 先验不是已知重力

现有代码使用源 +Z 定法向正负，默认 normal_up_min_z=0.5，等价于容许约60度倾斜。它是宽松安装先验，不是 IMU 已验证的重力方向。

需要先确认雷达轴约定和实际安装大致方向。没有这条信息时，使用人工确认的地面区域和物理朝向确认；不能把约束死设在“世界 Z”，因为世界 Z 正是要建立的未知量。IMU 四元数无效、轴/安装未验收时不作为本单真值。

### 3.3 旧 bag 的低支持率不能直接证明是假地面

returns/HF-03.md 历史记录：真实 bag 候选平面拟合内点 RMS 约0.018m，留出支持 RMS 约0.019m，支持率约0.242，低于默认0.5门槛，因此产物拒绝。全场景留出 RMS 约1.439m，其中包含非地面点。

本轮未重放该 bag。能确认的结论只有“旧验证门槛未通过”；不能只凭24.2%判平面不是地面，也不能凭1.9cm残差证明它是地面。需查看实际支持点、地面 ROI、覆盖范围及独立测量。先改变采样/验证设计，再讨论阈值，而非直接降到0.2让旧数据通过。

### 3.4 随机点留出不够代表场景泛化

目前对汇总点随机拆拟合/留出。固定多帧中相同表面可能同时进入两组，残差小不代表不同位置都可信。新验证应按采集时段/帧组及空间区域分离，优先在几块独立可确认地面上验证。

### 3.5 留出残差门槛的辨别力有限

当前支持点定义为距离平面不超过0.05m，而支持点 RMS 门槛是0.12m。对这一集合，RMS天然不超过0.05m，所以0.12m门槛不会再区分拟合质量。当前计数/支持率仍可能拒绝错误结果，但不能把这个 RMS 检查称为强精度保证。

后续应分别报告支持率、截断集合残差、独立已知地面区域上的未截断误差与高分位误差，依据任务允许高度误差决定门槛；本轮不修改参数或断言。

### 3.6 候选框参考坐标不能只转换两个角

`core/lidar_candidates.py` 的 _reference_features 当前对源 bbox 的 min/max 两角进行变换后取逐轴 min/max。这在一般非零旋转下不能得到正确的参考系外包盒。

后续有两种合法实现：源盒八角统一变换，展示同一个旋转后的盒；或变换候选真实点集后重新算地面 AABB。两者含义不同，需要在契约与网页标签中写清。现有 UI 主要画 source 框，因此不能推断截图的源框已经受此参考框问题影响。

## 4. 选定的初始标定方法

### 4.1 数据与地面身份

固定设备，采集无行人遮挡的短时场景；取得粗略安装高度和轴向说明，人工确认若干地面区域。区域可从已有离线三维点云确定，不要求先增加复杂网页框选系统。保留原始点索引、时间、frame 与样本哈希。

不能对倾斜雷达直接用原始 z 的窄带硬切“地面”。根据实际安装先验定义较宽的可见区域，必要时由现场人员确认；墙、桌面和低柜必须列为竞争平面。

### 4.2 拟合

对标定样本做有界空间均衡采样，避免一面近墙因密度大占满预算；在明确 ROI / 先验范围内进行方向约束 RANSAC。以距离平面阈值获得内点，对内点中心化后用 SVD 或3×3协方差特征分解精修，重算支持与误差。

安装高度范围用作一致性检查，不作为伪造测量值的来源。方向/高度/空间覆盖/独立验证都通过，且地面身份已确认，才提交可启用标定。几何数据不足时明确失败。

数值阈值暂不定成最终验收值：现有0.05m只能作为旧基线参数，实际距离噪声需分近/中/远区域测量；空间采样尺度、迭代预算、最小支持数和法向稳定门槛需在方案验证报告中给证据。不能移植 PCL 教程0.01m或 Patchwork++ 默认0.125m就宣称合适。

### 4.3 多帧验证与冻结

使用不同帧组/区域检查法向与 d 的稳定性。确认至少三个有空间分布的地面验证区、一个尺量高度的静止参考物；记录误差和测量不确定度。真实场地资料缺失时，只能确定软件方法，不能标定验收。

标定完成后保存版本化 R/t 与原始 n/d、有效范围和来源。固定安装每帧应用同一变换；低频检验可信区域残差，出现足够连续证据时失效并要求重标定。地面本身无法检测所有水平位移或绕法向旋转，不声称具备完整设备移动检测能力。

## 5. 配平方法选择与推导

配平选择直接构造正交基，不先拟合 Euler 角再串联旋转。以下为由平面方程与坐标约定推导的项目方案，不是网页引用的现成完整外参求解算法。

设源系平面 `n·p+d=0`，n为已确认向上的单位法向，传感器位于地面上方时d>0。

1. 原点取传感器原点在地面上的垂足 `o=-d*n`。
2. 选择并记录参考朝向 a（默认经轴约定确认的源 +X）；水平轴 `u=(a-(a·n)n)/||a-(a·n)n||`。
3. 第二水平轴 `v=n×u`。如果投影长度接近零则拒绝当前朝向，明确换参考轴，不任意自动翻转。
4. `R=[u.T;v.T;n.T]`，`t=-R*o`，因此 `p_ground=R*p_source+t`。
5. 数值检验 `R*R.T=I`、`det(R)=+1`、正逆变换一致；地面点Z接近0、雷达原点Z等于d、所有点Z等于`n·p+d`。

这能给出配平坐标所需的完整数值变换，但其水平朝向和原点部分来自约定。平面只能测出法向与距离，不能测出沿平面两个方向的位置和绕法向的绝对 yaw。如果需要房间前向，补墙边/场地标线；需要底盘前向，补安装测量。

在斜坡上，ground Z指地面法向；若任务需要重力竖直，须单独验证平整场地条件或增加有效重力参考。本单先限定平整室内场地。

## 6. 在线地面分类与人体点保留

初始地面标定和每帧地面分类是不同任务。固定平面可通过`h=n·p+d`计算每点离地高度，不需要每帧重新 RANSAC 再更新 R/t。

地面显示可以给可信地面支持点着色；人体算法不能简单把所有|h|小于固定阈值的点永久删掉：脚、倒地躯干边缘会贴近地面，可能一起被删。保留原始点和分类证据，地面处理与低姿态目标保留需按现有候选流程核对。复杂地面分类才考虑区域模型，不能直接用强地面剔除掩盖大框问题。

## 7. 开发前审查关卡

本轮选定“约束RANSAC+SVD+固定地面变换”为首选设计；真实数据效果与参数尚未批准。本轮不把该设计写成已实测PASS。

后续执行分三道关卡，不允许一条提示词自动跨过全部关卡：

1. **方法/数据审查**：只读确认真实点云地面可见性、轴向/高度先验、场地平整条件、ROI和既有失败原因。提交采样与验证方案、契约最小扩展及阈值依据。Codex 审核通过后才实施原型。
2. **原型结果审查**：隔离环境比较旧基线与选定方法；测试墙占多数、桌面竞争、缺地面、倾斜、多区域。提交支持点可视化、实际误差、耗时和失败案例。不能只报总测试数。通过后才接正式算法/网页消费链。
3. **集成与物理验收**：点云/盒子/二维投影/俯瞰/读数同版本；新标定使旧基线失效；尺量与独立地面误差通过。正式部署仍按已有授权及回滚流程处理。

如果第一关确认单平面前提不成立，提交分区域方案与数据证据，重新评估 Patchwork++ / LineFit，而非实现者随意换库。如果缺现场信息，列出具体缺项；可继续数学/接口方案审查，但不越过真实数据结论。
