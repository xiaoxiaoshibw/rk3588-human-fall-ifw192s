## 1. 结论摘要

真实配平未产出的原因不是单点故障，而是**四层串联**的阻塞。前三层各有明确证据与可讨论的修法；**第四层是协议设计假设与本场景几何不相容，属于需要决策的语义问题**。

| 层 | 阻塞 | 证据强度 | 性质 |
|---|---|---|---|
| **L1** | `up_axis` 把俯角写成仰角（26° 数值正确、X 分量符号反） | **强**（跨 10 帧稳定） | 人工填写，疑似符号错误 |
| **L2** | fit ROI 过小 → 采样点数低于 `min_inliers` | **强**（可精确复算） | 选框过小，非数据不足 |
| **L3** | `offset` 在传感器原点比较，被距离×角度差几何放大 | **强**（数值吻合） | 判定口径问题 |
| **L4** | 验证区为传感器轴对齐盒，与 25.6° 倾斜地面不相容 | **强**（逐区量化） | **协议语义，需决策** |

旧文档 `evidence/2026-10-03_gl_i02_r1/codex_review_01/13_route3_closeout.md` 记载的根因是"单帧 ~1214 点 → 数学上不可行"。**该记载的前提有误**，见 §2.2。

## 2. 逐层证据

### 2.1 L1 — `up_axis` 符号

**决策链复原：**

| 环节 | 事实 |
|---|---|
| `draft_template.json` | `"up_axis": null` —— 脚本**不生成**该值，必须人工填 |
| `13_route3_closeout.md:66` | "`up_axis = [0.438371, 0, 0.898794]`（用户确认，雷达 Z 倾斜朝地板 26°）" |
| `evidence/2026-10-01_gl01_r4/CODEX_REVIEW.md:7` | 26° 来自 "hardware_inventory 新增**人工截图俯角估计约 26 度**（25～27度）"，并明确 "**其为截图粗估，不作为已验证安装角**" |
| 数值反推 | `asin(0.438371) = 26.0000°`；值形如 `[sin26°, 0, cos26°]` |

**数据侧实测（独立 RANSAC + SVD，无角度门）：**

| 量 | 实测 |
|---|---|
| 主导平面法向 | `[-0.4424, -0.01, 0.8968]`（多帧一致，见 §2.5） |
| 与**声明** up `[+0.438, 0, +0.899]` 夹角 | **52.26°** |
| 与**翻转** up `[-0.438, 0, +0.899]` 夹角 | **0.41°** |
| 协议角度门 `max_angle_rad` | `0.2617993877991494` = **15°** |

**几何解释：** 按标准传感器系（X前/Y左/Z上），传感器**俯**角 θ 时世界竖直在传感器系表达为 `(-sinθ, 0, cosθ)`；**仰**角才是 `(+sinθ, 0, cosθ)`。硬件盘点与用户描述一致指向"雷达向下看"，故 `[+sin26°, 0, cos26°]` 与安装事实**方向相反**。

**注：** 52.26° ≈ 2 × 26°。符号反使偏差翻倍，并被 15° 角度门完全拒止 —— 走满 861 次迭代产出 0 候选，报 `ground_degenerate`。该错误码描述的是"RANSAC 未找到"，**不是"数据中没有平面"**。

**边界：** 26° 本身即非测量值；翻转 up 为反证实验；正确的安装角/source 系 world-up 表达仍为 **unknown**，需 B02 现场证据闭合。

### 2.2 L2 — fit ROI 尺寸

文档记载"单帧 ~1214 点"。实测该帧（`frame:3d854c4e9c848ce08fb1e058`）：

| 量 | 值 |
|---|---|
| 该帧总点数 | **49,130** |
| 非零点数 | **41,555** |
| 草稿 fit ROI（1m×1m）内点数 | 1,214 |
| `_balanced_sample` 后 | **80** |
| `min_inliers` 门槛 | **100** |
| 结果 | `ground_points_insufficient`（差 20） |

`✶` **1214 是 ROI 内的点数，不是帧的点数。** `_balanced_sample`（`ground.py:542`）按 `spatial_cell_m=0.20` × `max_points_per_cell=4` 划网格抽稀，**格子数由 ROI 面积决定，与帧内总点数无关**。同一帧放大 ROI 后即越过门槛：

| ROI 尺寸 | ROI 内点数 | 采样后 | 门槛 100 |
|---|---|---|---|
| 1.0 × 1.0 m（原） | 1,586 | 103 | 勉强过 |
| 1.0 × 1.0 m（草稿实际 y 范围） | 1,214 | **80** | **FAIL** |
| 2.0 × 2.0 m | 3,593 | 256 | OK |
| 4.0 × 4.0 m | 5,273 | 426 | OK |

**故"单帧点太少、数学上不可行"的前提不成立。** 本层为选框过小。

### 2.3 L3 — `offset` 比较口径

放大 ROI + 翻转 up 后，管线找到地面，但报 `ground_competition_unresolved`。`raw_candidates` 达 `_COMPETITION_CANDIDATE_CAP = 8` 触发截断 → 按协议保守拒绝。提高 `max_points_per_cell` 后转为 `ground_orientation_ambiguous`：

```
候选0: offset=1.3196  support=1685  angle_to_up=1.54°
候选1: offset=1.4284  support=1658  angle_to_up=3.09°
```

第二候选支持数仅差 27（比值 0.984 > `support_close_ratio=0.8`），offset 差 0.1088 m > `distinct_offset_m=0.05`，且夹角 3.03° ≤ `distinct_normal_deg=10` → 判为"接近且可区分" → 模糊。

**但两者在点云质心处几乎重合：**

| 比较位置 | 候选0 | 候选1 | 差 |
|---|---|---|---|
| 传感器原点（协议所用） | 1.3196 | 1.4284 | **0.1088 m** |
| 点云质心 `(2.411, -0.932, -0.179)` | +0.10225 | +0.09445 | **0.00780 m** |

`✶` `offset_m = -n·p0` 是**在传感器原点处**量的有符号距离。法向存在微小角度差 Δθ 时，同一真实平面在远处的 offset 会整体偏移约 `|p| · sin(Δθ)`：

- 质心距原点 `|p| = 2.591 m`，`Δθ = 3.027°`
- 预测 offset 差 = `2.591 × sin(3.027°) = 0.1368 m`
- 实测 offset 差 = `0.1088 m` ✓ 同量级吻合

两候选 5cm 内点集交集 **1633 / 1685**，进一步证实为**同一物理粗糙面的两种拟合**。

**结论：`ground_competition_unresolved` 是 offset 比较口径的几何伪影，不是"多个面在竞争"。**

**但调阈值不是解药**（只改 `distinct_offset_m`，纯参数实验）：

| `distinct_offset_m` | 结果 |
|---|---|
| 0.05（默认） | `ground_orientation_ambiguous`，2 候选 |
| 0.08 / 0.11 | `ground_orientation_ambiguous`，3 候选 |
| **0.15** | **`ground_validation_failed`**，1 候选 |
| 0.20 / 0.30 | `ground_validation_failed`，2 候选 |

放宽后阻塞**后移至验证区**，暴露 L4。

### 2.4 L4 — 验证区定义与倾斜地面不相容（本报告核心发现）

阈值放宽至 0.15 后管线产出 1 个候选，三个验证区残差**全部不合格**：

| 验证区 | 点数 | RMS | p95 | support_fraction | 门槛 |
|---|---|---|---|---|---|
| v1 | 2,064 | **0.0523** | **0.0974** | **0.585** | RMS≤0.03, p95≤0.05, frac≥0.8 |
| v2 | 119 | **0.1193** | **0.3242** | 0.782 | 同上 |
| v3 | 542 | **0.0819** | **0.2000** | 0.744 | 同上 |

进一步把各区点投影到拟合法向、量**真实离地高度**（正=平面上方）：

| 区 | 点数 | z 带范围 | 平面穿过 | **h < −5cm（地面下方）** | **h > +5cm（地面上方）** |
|---|---|---|---|---|---|
| v1 | 2064 | −1.06 … −0.57 | 是 | **39.5%** | 2.0% |
| v2 | 119 | −0.10 … +0.59 | 是 | 0.0% | **21.8%** |
| v3 | 542 | −0.15 … +0.55 | 是 | 0.2% | **25.5%** |

**没有任一验证区干净落在地面上**：v1 有近四成点"陷到地面以下"，v2/v3 各有两成以上点"浮在地面以上"。

**根因：** 三个区均以 `x/y/z_min_m/max_m` 六个**传感器轴对齐边界**定义，而拟合地面在传感器系中是**倾斜的**：

- `dz/dx = −0.4313 / 0.9019 = −0.478` → **25.56°**
- v2/v3 的 x 跨度 1.0 m 对应地面高度变化 **0.478 m**，而盒带高仅 0.69 / 0.70 m —— 同量级
- v1 的 x 跨度 0.60 m 对应高度变化 0.287 m，盒带高 0.49 m

`✶` 轴对齐盒隐含假设"地面大致垂直于某坐标轴"。26° 倾斜安装下该假设不成立，**框内必然混入非地面点**，`support_fraction ≥ 0.8` 与 `RMS ≤ 0.03` 在几何上难以同时满足。

协议要求"≥3 个独立验证区"以防过拟合，思路正确；**冲突在于区域的**定义方式**，不在区域数量。
