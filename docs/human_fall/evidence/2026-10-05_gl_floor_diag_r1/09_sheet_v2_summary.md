# floor-sheet v2 只读验证（A/B 分层）结论

## 设计原则

- **A 层**：`RANSAC 面 → ±ε 薄层 → 5cm 细格占用（多帧投票）→ 连通组件 → 有界触面桥接`
- **B 层**：v1 全部 25cm 干净格门一个不降 → 四区最小间距/独立性/条件数
- `LOCK = A_floor_identity ∧ B_fit_support`，两层独立硬门，第一版不做加权黑盒分。
- 全程只读：不改 v1、不写 snapshot、不影响旧报告。

## 参数（provisional，待合成回归标定）

| 参数 | 值 |
|---|---|
| 薄层 ε | 0.03 m（同时跑 0.05 m 敏感性） |
| 细格 / 占用 | 5cm；≥10 点、≥20 帧、帧命中率 ≥30% |
| 触面 τ / 比例 | 5cm；接触比 ≥0.5 且缺口靠点 ≥5 |
| 桥接宽度上限 | ≤4 格（0.2m）；仅当最大片 <0.5m² 时才需要桥接 |
| 显著碎片 | ≥0.25 m²（更小的卫星片只报告，不参与否决） |
| 连通 | 有效面积 ≥0.5m² 且有效覆盖率 ≥0.5 |
| 身份主导 | 最低面 offset 边界不变；与次低面间距 ≥5cm；体素份额 ≥0.30 |
| 时序稳定 | 最大组件逐帧覆盖 p05 ≥0.30 |
| B 四区 | ≥4 格、两两最小间距 ≥0.5m、独立计数=4、条件数 ≥0.1 |

1. **223757 拿到预期 golden 行为**：A 层确认"地面身份基本成立（7m² 连续薄层、多帧稳定）"，B 层确认"6 格分两簇、无 4 个分散干净区"，FINAL 拒绝原因从模糊的"没有连续地面"变成精确的 `INSUFFICIENT_CLEAN_ROI_SUPPORT`。v1 记录不改，拒绝结论不变。

3. ε=0.03 与 0.05 结论一致（面积约 +10~20%），薄层厚度未卡在临界。

## 尚未被真实数据触发的路径（合成回归必须先覆盖）

1. **桥接逻辑本身**：4 个会话最大片都 ≥4m²，`bridging_needed=False`，触面桥接一次都没执行——需要用合成用例验证（分散小片拒绝、障碍触面合并、同高多桌面拒绝、坡面/2–4cm 起伏不被 ε 切断）。
2. **203135 的第二显著碎片**（292 格 0.73m²，与主片间有一个 ≤4 格、触面比不足的未解释缺口）目前不影响结论（不需要桥接）；合成回归要定夺"小而未解释缺口"是允许还是警告。
3. **错误面风险**（地面不可见、最低面是桌面）仍靠 `lowest/dominant` 门兜底，其阈值（间距 5cm、份额 0.30）属 provisional，需要专门反例标定。
