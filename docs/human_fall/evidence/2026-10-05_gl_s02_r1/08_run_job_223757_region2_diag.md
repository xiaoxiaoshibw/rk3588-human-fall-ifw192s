## 区域 2 是什么

display x ∈ [.9, 1.05]、y ∈ [-.45, -.3]，对应源 x ∈ [1.385, 1.554] 0.17m 窄带。源 z 分布连续单峰（-0.88..-0.74），盒内 PCA RMS 0.023m、local_normal_z 0.985——**盒内是干净的**；但相对全局 TLS/SVD 平面偏离 6cm 量级，且源 x 残差中位数随距离系统漂移（0.75m 处 -16mm → 2m 处 +20mm）。

结论（**已被 `10_r2_rootcause_probe.json` 与穷举证伪，保留作历史**）：初判"该区域是真实非平面/GL 门正确拒绝"不成立。真正根因是 `_select_four` 不看单盒 rms，把全组最差的 0.0234 盒挑进了四区；穷举 C(34,4) 证明存在 max 单盒 rms=0.0127、同契约下三法质量门全 PASS 的组合。选择器返工后（可行集内优先低 rms，门不降）223757 全流程三法全过、recommended=tls——见 `07_run_job_223757.json`。本文件仅留作"错误归因"的反例。
