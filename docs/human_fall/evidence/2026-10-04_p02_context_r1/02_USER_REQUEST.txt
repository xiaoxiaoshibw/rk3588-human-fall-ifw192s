# 四、已经冻结的数学结论

以下内容已经经过多轮分析，不要无理由重新推翻。

---

## 4.1 坐标变换基本形式

采用：

```text
p_G = R · p_S + t
```

其中：

S = LiDAR/source frame

G = ground/world frame

ground/world：

```text
+Z = vertical up
```

当前 ground-leveling 只估：

```text
pitch
roll
tz
```

yaw 对当前 ground-leveling 是 gauge freedom：

```text
yaw = 0
```

水平 tx/ty 当前也不是主要标定目标。

---

## 4.2 世界水平约束

如果某个 source-frame 平面的单位法向：

```text
n_S
```

已经被物理证明确认为水平参考面，

则：

```text
R · n_S = [0, 0, 1]^T
```

可用于约束 ground-leveling 的 pitch / roll。

注意：

> “存在一个稳定平面”

不等于

> “这个平面就是世界水平面”。

这两者必须分开。

---

## 4.3 Plane offset 与高度的正确关系

平面采用：

```text
n_S^T · p_S + d_S = 0
```

且：

```text
||n_S|| = 1
```

如果该平面已经被确认是水平 ground，且：

```text
ground z_G = 0
```

那么：

```text
tz = d_S
```

按 normal sign convention 统一符号。

物理高度通常取相应正值。

**禁止再使用：**

```text
H = d / |n_z|
```

该表达式得到的是 source-frame Z 轴与斜平面的交点深度，不是 ground-frame 中 LiDAR origin 的竖直高度。

仓库已有几何契约也明确：

> 向上法向、地面在传感器下方时，原点离地高度对应 d。

---

## 4.4 refit RMS 已被证死

以下 objective：

```text
transform points
→ refit best plane
→ compute point-to-refitted-plane RMS
```

不能用于 extrinsic calibration。

原因：

刚体旋转和平移后重新拟合自己的最佳平面：

点到该最佳平面的正交残差是刚体不变量。

真实数据已经验证过类似：

```text
不同 pitch / roll / tz
refit_RMS 基本完全相同
```

因此：

> REFIT_RMS SHALL NOT be used as an extrinsic observability/calibration objective.

不要重新投资这个方向。
