# HF-06 特征融合与跌倒时序状态机
执行：OpenCode DeepSeek v4.1 Flash。依赖：HF-01 契约冻结、HF-02～05 有效观测。状态：WAIT_DEPENDENCY。

先读 ../DISPATCH.md 并读取 ponytail SKILL.md。本单实现可解释规则基线，不训练时序大模型。

## 工作与代码
- core/features.py：对已锁定且有实测点云的同一目标计算地面相对高度分位数、几何主轴/水平范围、下降速率与近地面持续时间。退化主轴标未知，用稳健统计，不把点云中心等同解剖质心，不声称有关键点/躯干骨架。
- core/fall_state.py：unknown/upright/descending/low_posture_unclassified/suspected/confirmed/recovering，状态规则写清必要证据与允许时序；用秒表示持续时间，不用固定帧数假装恒定帧率。
- confirmed 需本目标的有效下降历史与持续低姿态/近地面证据。启动就躺着仅报未分类低姿态；蹲坐弯腰或无下降历史不因低高度报警。允许报告尚未覆盖的慢滑落等类型。
- 时钟回退、设备运动、地面失效、必需点云过期、track 歧义/丢失清动作历史并返回 unknown；点数不足或候选漏检不能当倒地。lidar_geometry 模式需独立验收才可 confirmed；IMU 辅助是否必需按模式契约决定，单位/旋转未知时不能偷用于融合。
- confirmed 产生稳定 event_id 并去重；当前观测变 unknown 不撤销已有事件。恢复/人工确认与已存事件分离，重新站起不造成同一事件连续触发。
- 阈值在配置中有单位和来源；样本调参/盲测严格分开。

## 验收
有效站立→下降→低姿态→持续→确认；恢复后新事件；下蹲/坐椅子/弯腰/捡物/主动躺下；初始化已躺、慢滑、预测代观测、帧丢失、时间跳变和切目标。同一回放结果确定性一致、无 NaN、同事件只一次。特别记录主动躺下可能与跌倒无法区分的实测边界，不承诺规则必然区分。
