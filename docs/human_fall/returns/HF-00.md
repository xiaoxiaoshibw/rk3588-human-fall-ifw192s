## 风险与边界

- 设备时钟无 UTC 锚定、速率比/漂移未测量；禁止用频率数值代替同步证据；点云↔IMU 固定偏移未测（HF-02）。
- 点云帧含 `x=y=z=0` 无效点且 `is_dense=False`；`timestamp` 字段 8 字节非对齐，解析方需注意。
- `orientation`/covariance 全 0 会被通用工具当作"有姿态"，使用方必须显式忽略。
- 板上工作副本不是 git 仓库；Windows 副本与板上运行配置不一致（`msg_source: 2` vs `1`），涉及运行行为的结论以板上为准并注明来源。
- 容器 `devel` 残留旧工程 `ros_interface`（CameraParkingInfo 等），勿当作相机存在证据。
- `abnormal_flag=255`、ttyACM0-3/CAN 用途未解释；未验证不代表不存在问题。
- 真实跌倒/姿态性能、模型能力、端到端延迟不在本工单范围，均未测。
