## 范围内完成项

1. **PLAN 数学（`core/calibration.py`）**：`ground_derived_basis` 由已验证地面构造 `o=-d*n`、`u=单位化(a- (a·n)n)`、`v=n×u`、`R=[u;v;n]`（行）、`t=-R@o`，`p_ground=R@p+t`；参考轴近似法向（投影<0.05）明确拒绝。
2. **严格校验**：`validate_ground_derived` 拒绝非单位 n、非刚体/反射 R、R 与 n/参考轴投影不一致、t 与 n/d 不一致、错误/未知嵌套版本、非法单位/frame、非法 region、损坏的 `ground_derived_id`（内容重算比对）、以及预置 `physical_verified=true`/`single_plane_confirmed=true`。`apply_ground_derived`/`ground_derived_inverse` 提供正/逆变换。
3. **三个条件分离**：`ground_derived_status` 分别输出 `geometric_usable` / `ground_identity_confirmed` / `physical_height_verified`；候选仅诊断可用，永不进入已验证离地结论。
4. **兼容产物**：`build_geometry_calibration(..., ground_derived=)` 仅新增可选 `ground_derived` 块；`validate_geometry_calibration` 加载时严格校验该块，未知嵌套版本即拒绝（地面模式回落源视图，不默认绿）；旧 v1 无新字段原义不变，`extrinsics_verified`/`ground_physical_verified` 保持 false，不冒用 measured_mount。
5. **CLI 导出**：`calibrate_sensors.py --constrained --ground-derived --reference-axis X Y Z` 导出新版本产物；已存在输出且使用派生时拒绝覆盖（rc2），缺参考轴/无有效地面拒绝（rc2）。记录 `ground_derived_id` 绑定规范化内容与来源（path/sha256/frame）。
6. **生命周期入口（`core/node_runtime.py`）**：`apply_ground_context()` 为显式启动/重载边界；`ground_derived_id` 变化即 `baseline.invalidate("ground_derived_changed")`、清空快照缓存与最近有效快照/位置，记录 `ground_derived_lifecycle`；源 seq/stamp/epoch 不变。无通用热更新框架。
