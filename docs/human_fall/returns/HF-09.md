## 契约与实现

- **时钟**：ROS 节点所有路径用同机 `time.monotonic`；离线 `fall_replay.py` 独立保留消息时间域，未改。
  `performance` 为 `state` 的**可选新增字段**，`schema_version` 不变，冻结 health/manifest 不变。
- **空输出语义**：required cloud 缺失/非法/过期 → `observability=invalid`、`fall_status=unknown`，
  position/range/bbox/预测全 `null`，nested `target_features.observable=False`、`fall_state` unknown；
  输入恢复后按合法实测重建，不用定时器制造下降。
- **测量口径**：处理延迟 = 节点自报 `process_s`；`receive_to_finish`/`queue_age` 同为节点自报；
  `queue_dropped` = 队列覆盖计数；observer 到达→state 差单列为次要值。
