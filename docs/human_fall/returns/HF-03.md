## 契约与实现

- 坐标系/单位：长度 m、角度 rad；`T_from_to` 表示 `p_to = R @ p_from + t`；`R_lidar_imu` 表示 IMU 向量→LiDAR 系。地面 `n·p+d=0`，法向朝上（`n_z≥0`）并位于原点下方时传感器高度 `=d>0`；法向/高度不可证明时保持未验证。真实参考系未建立，产物 `frames.reference=null`，后续网页/位置仍应标为雷达坐标 `innolidar`，稳健点云中心/地面投影定义留给 HF-05/11。
- 诚实边界：无证据的外参/IMU 旋转不写数值；`synthetic` 证据只标 `synthetic`，绝不升级 `verified`；`verification.*_verified=true` 与 unknown/synthetic 记录矛盾时校验报错；地面 `valid` 需同时满足单位法向、朝上、正高度、有效区域与**非空留出残差**，统计本身不等于通过。
- 复用了 `sensor_health.save_json/dumps_strict/load_config/_load_xyz_from_cloud` 与既有点云解码，避免重复实现；纯计算只用 NumPy/标准库；未引入相机/PnP/OpenCV/新依赖。
- 早期独立复核修复（Codex `review_hf03_codex.py`，修复前 5 方法/3 失败，日志 `codex_initial_geometry_boundaries.txt`）：
  - **P1 内存**：`ground.py` 的 SVD 改为 `full_matrices=False`（细 SVD，U 为 N×3），满足板上有界内存；新增较大数组有界/封顶测试。另核实本单无其他 NxN `linalg` 调用（仅 3×3 `det`）。
  - **P2 门控**：新增留出支持率与残差双阈值（`min_holdout_support`、`max_holdout_rms_m`、`min_holdout_points`），留出不足或整体离面即 `ground_holdout_insufficient`/`ground_holdout_failed`，不再只报统计；保留原始残差。
  - **P3 结构**：`validate_ground_plane` 严格要求单位法向/朝向/高度/帧/有效区域/留出残差；旋转记录 status 必须与 evidence 一致；验证标记不得与 unknown/synthetic 记录矛盾；配置参数同步做有限值与范围校验（如 `normal_up_min_z∈[0,1]`、`holdout_fraction∈[0,1)`、`min_holdout_support∈[0,1]`）。
