# 因果窗口与独立环境离线研究（2026-10-22）

本轮使用用户授权的公开数据下载、核对与离线训练范围。保留首轮模型及全部旧数据；没有设备连接、部署、采集、服务启停、驱动网络修改或 confirmed 启用。

## 实验契约

输入仍为 `sequence_xyz_v1`：每帧19维XYZ几何量，窗口内汇总为114维。复用首轮特征公式和RF参数（200树、depth16、leaf2、balanced、seed42、4线程），不归一化、不搜索参数、不拟合置信阈值，以argmax输出整段动作类别。

10/20/30/60帧窗口全部保留；30帧预先指定为主要候选。步长均为10帧，起点为第0个输入帧，无未来填充、无按序列尾端对齐。每次输出仅访问截止时刻及之前的点云。复用首轮5个模型的人员划分，每折8人训练、2人留出，同一人的全部动作和重叠窗口始终同折。所有配置是E01内的探索性比较，不把留出成绩包装为嵌套选型验证。

窗口标签一律为 `inherited_sequence_action`。关节标注仅检查有限值、形状与点云帧数对齐，不进入特征。连续编号与297个关节记录相符不等于核实动作起止；作者动作区间、逐帧动作GT与跌倒起始仍UNKNOWN。MM-Fi的27类动作中没有本轮可用于真实跌倒指标的标签。

窗口概率逐条保存；完整序列聚合为各窗口概率均值。聚合结果使用了序列内多个截止时刻，只是回顾性序列汇总，不能解释为第30帧实时成绩。另有首窗口结果，和旧前缀实验区分。相关窗口不当作独立人次，不报告虚假的窗口独立置信区间。

E01开发比较后，四种窗口的全量E01权重、RF参数、动作ID映射、特征源码SHA、旧模型SHA及采样/聚合规则写入 `FREEZE.json`；此后才开始E02下载。E02只测试这些冻结配置；若后续以其成绩调参，E02须改称开发集，E03/E04继续保留。

证据中的 `E02_download/E02_DOWNLOAD.json` 保留每个原始ZIP成员的CRC与SHA，`E02_HTTP_PROBE.json`、`E02_DISK.json` 保留206范围响应与磁盘核查。不下载相机、WiFi或毫米波。E01与E02的人员不同，跨环境与跨人员变化同时存在，不能把下降全部归因于环境。E02没有训练、拟合归一化、选型或阈值拟合；E03/E04未读取训练/测试数据。

## IFW192S来源与本地候选

本轮重新核对21段meta，共4,472声明帧；其中 `cap_20261020_172855` 缺少points.bin（47帧），其余20段共4,425帧原始点云存在。meta、points SHA与完整时间/offset记录保留在 `TARGET_SOURCE_BINDING.json`；所有meta的human_annotations均为空。9份历史非e2e对象GT的manifest SHA相符，但原录制不在当前根目录、也无结构化动作/姿态/跌倒字段，不能移绑当前录制，不能把PERSON解释为站立。

新增 `lidar_numpy_runtime.py` 只依赖stdlib+NumPy，Python3.8语法通过；未在原生Python3.8/NumPy1.17板端执行。RF导出为数值NPZ，分裂时先按sklearn契约转换float32，再与float64阈值比较。非法特征、非法树索引和循环被拒绝；保存/重载、阈值边界与相邻float32值、全部30帧留出特征及本地回放均有逐值核对。概率容差1e-14，类别必须一致。

缓存只保留最近30帧的帧特征；身份、代际、选择版本、时间epoch、标定版本变化，时间倒退/重复/超过0.5秒断档，以及非法帧均清空历史。无有效实测目标也清空。训练/评估采样步长10，本地候选每个有效帧输出一次，均明确记录；这不产生额外独立样本。

本地原始文件回放采用 `cap_20261018_110029` 的386帧：逐帧seek/read并解码28字节点布局，跑完整检测/跟踪/成员/几何/状态链，再将当帧实测目标点交给只读模型旁路。原始meta/points与历史地面标定的同源SHA核对通过；该标定的physical_verified/extrinsics_verified/runtime_eligible仍false。前50帧为空背景是既有开发假设，非人体GT；原始XYZ未拟合到MM-Fi传感器坐标系。

预热一对、交替串行测量三对，共8次完整回放。模型旁路不影响完整result/baseline的逐帧SHA。每次产生229个可推理窗口，首次输出frame145；从当前连续有效段开始等待30帧，实际源时间差3.006258秒。三轮缓存/特征P95分别1.270/0.846/0.941ms；模型就绪帧推理P95分别0.544/0.375/0.429ms。加入模型的读原始文件+解码+整链处理P95分别36.054/24.577/25.252ms，基线分别24.906/25.422/41.399ms；波动明显，不声称整链提速，也不能仅用推理时间代替整链性能。

这些计时在PC暖文件缓存、后台下载等负载下完成；读解码/链/模型的处理时间排除核对断言及结果序列化，包含核对的整次调用时间另存。初始化完整解码/验证单列1.420秒；不含ROS接收、调度、显示、网络、真实丢帧或板端时间。没有动作/跌倒真值，目标域accuracy、真实跌倒召回、人体语义与物理有效性仍UNKNOWN。
