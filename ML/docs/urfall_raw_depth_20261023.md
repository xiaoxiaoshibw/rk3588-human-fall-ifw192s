## 原始数据与坐标

官方资源由 [UR Fall 页面](https://fenix.ur.edu.pl/~mkepski/ds/uf.html) 提供，许可 CC BY-NC-SA 4.0。前视跌倒 PNG16 用 6000、日常用 7000 换算毫米，再转米。原先两段深度加新增 68 段，共 70 个原始深度 ZIP，逐文件 SHA 和 ZIP/成员 CRC 入账；新增 68 段为 2,233,370,776 B，保留于 `data/downloads/urfall_depth_20261023_v1/`。

论文 [Human fall detection on embedded platform](https://repozytorium.ur.edu.pl/bitstreams/43e68a80-9300-4366-996e-3b24a0aadc74/download) §5.2 给出 f=580 像素。配置 `ML/config/urfall_cam0_nominal_v1.json` 用此标称焦距，假定方形像素和中心主点，不假称这批文件有逐台标定；失真未核实。源码坐标为 x 右、y 深度、z 上。相机参数必须显式提供，物理资格固定 false。

采样保留原始全分辨率像素 ID；零深度不作观测。预热只消费此前 0.3 s，背景为该前缀的有效深度逐像素下中位数，可能含人；地面拟合复用现有 `core.ground`，验证门限未放宽。下方 40% 与底部四分之一只改变地面拟合输入，不裁剪人体目标区域。前景差分、体素组件和实测关联保留生成号、点数、来源像素和失败原因；最大组件仍不等于人体语义。

在 fall-01 上，160 帧、138166 个所选点均由原始像素精确重建；修复前后来源像素不变。90 帧前缀与全长前缀逐值一致。标称焦距 ±10% 的诊断均形成候选，但不证明真实内参误差界或普遍鲁棒性。核对图位于 `visual_audit/`，对应下方 40% 的诊断条件。

## 修复的根因

1. PCA 近似各向同性时只遮蔽角度。高度、跨度和速度仍来自实际观测，不能把整帧清零或打断高度连续段。
2. 保留过去 2 s 实测直立高度的高位参照，而非被每个仍显直立但已下降的帧反复覆盖；真实断档、身份/代际/标定变化仍清空历史。
3. 若角度没有提供中间姿态，用实际采到的中间高度证明过程：样本须落在实测总下降中间的一半范围，并位于高位参照和当前帧之间。没有插值，也不把端点毫米级噪声当作过程。下降门限 0.35 m 不变。
4. 已建立低位保持后，若仅角度缺测，但高度 ≤0.8 m、跨度 ≤1.10 m 且实测连续，则保持低位证据；不填造角度。高度超界、明确反向姿态或真实缺测仍打断保持，0.3 s 保持门限不变。

两项后续修正分别消融，保存逐帧输出和源码 SHA。原始内核、仅角度修复、再加高位参照的早期对照也保留。协议与采集方案补充无人前缀/冻结背景，避免把初始静止受试者吸进背景。

## 保留的失败与边界

- fall-10：初始人体被背景相减削掉，取得目标时已经在下降，没有直立参照。这是提取器上下文损失，不是原始传感器必然不可见。
- fall-22：参考过渡从 0.1 s 开始，0.3 s 预热结束前已经下降。不能用未来地面/背景回填早期推理，也不把它从分母删除。
- ADL-23：当前原始链唯一日常触发；能定位到下降/低位几何相似，具体动作未经独立视频确认，不擅自写成“主动躺下”。作者特征中 ADL-32/33 也触发，均保留为困难负例。
- ADL-37：350 张原始深度但同步表只到 330，后 20 帧保留为缺时钟 UNKNOWN。原始总帧 11936，同步总帧 11916，不能拿平均帧率填时间。
- 场景、人员、点级人体真值和作者预处理因果性仍有缺口；原始链与作者特征不是两份新增独立人群。


最终证据在 `docs/evidence/2026-10-23_urfall_raw_depth/verified/`，两因素对照在 `masked_geometry_ablation/`，默认/地面输入对照在 `corpus_nominal/` 与 `corpus_lower_quarter/`。每次使用新输出目录。

`check_fall_geometry_compat.py` 提供可移植点集夹具，在本地隔离的 Python 3.8.10 / NumPy 1.17.4 与当前环境核对状态和数值，包括角度缺测、下降和事件锁存。它验证软件兼容性，不能替代 ARM/ROS/调度或板端实时性能。运行时位于 `.dsh_tmp/`，不修改系统 Python，不连接设备。

M2 已具备原始输入、点集来源、连续时间和完整回放的开发证据；标称相机资格、人体点集真值和目标域事件效果未因此补齐。后续先处理独立目标域数据与困难负例，再做时序模型对照，保持 confirmed 关闭。
