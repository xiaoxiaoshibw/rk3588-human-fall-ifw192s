# 论文笔记（arXiv，全部已下载 PDF 于 ../papers/）

判定维度：传感器 / 方法类别 / 对本项目（IFW192S 3D LiDAR、规则管线、RK3588）的可用性。

---

## 1. A Survey on Radar-Based Fall Detection（arXiv:2312.04037, 2023-12）
**PDF**: `2312.04037_Radar跌倒检测综述.pdf`

- 毫米波雷达跌倒检测系统综述：硬件、信号处理（Range-Doppler、微多普勒谱）、特征工程、规则 vs 学习分类器。
- 跌倒动力学描述对几何方法有用：自由落段时间量级、质心垂直加速度、姿态从直立到水平的转变。
- 明确点出**规则阈值法的优势**（无需标注数据集、实时、可解释）——支持我们首版决策。
- 适用性：★★☆ 传感器不同（毫米波 vs 光学 LiDAR），只读"跌倒的物理特征"和"系统架构"两章即可。

## 2. mmFall: Fall Detection using 4D mmWave Radar and Hybrid Variational RNN AutoEncoder（arXiv:2003.02386, 2020）
**PDF**: `2003.02386_mmFall_毫米波点云跌倒.pdf`

- 用毫米波雷达的点云，把每帧点云压缩成身体质心 + 协方差，训练**变分 RNN 自编码器**只在正常动作上训练，跌倒时重构误差→异常。
- **无监督**思路：不需要跌倒标注（现实数据稀缺），这点对我们后续若收集困难正例有参考价值。
- 质心+协方差的帧级表示与我们的 `features.py` 提取的几何摘要几乎同构——证明这种压缩足以支撑跌倒判别。
- 适用性：★★★ 传感器原理不同，但"点云→帧级描述子→时序异常"三段式架构可整体借鉴。

## 3. Environment-independent mmWave Fall Detection with Interacting Multiple Model（arXiv:2311.08755, 2023-11）
**PDF**: `2311.08755_IMM环境无关毫米波跌倒.pdf`

- **与本项目思路最接近的一篇**：把跌倒过程建模为多模型交互（站立→下降→倒地），用 IMM（Interacting Multiple Model）滤波在状态间软切换。
- 关键贡献"环境无关"：不依赖特定房间的预先标定背景，靠动态状态刻画 —— 对应我们 `ground.py` / 背景减除的痛点。
- 明确把"下降的垂直速度"与"倒地后的低高度持续"作为两个独立证据阶段 —— **同构于我们的 fall_state.py 时序状态机**，可作为理论背书引用。
- 适用性：★★★★ 虽为毫米波，但状态分解思想可直接映射到我们的规则引擎；IMM 滤波本身 RK3588 可跑（矩阵小）。

## 4. LiDAR-based Human Activity Recognition through Laplacian Spectral Analysis（arXiv:2509.23255, 2025-09）
**PDF**: `2509.23255_LiDAR人体活动识别_拉普拉斯谱.pdf` · **代码**: https://github.com/Arritmic/oulu-pointcloud-har

- **真正的 LiDAR 点云**（非毫米波），逐帧构建 ε-邻近图，取拉普拉斯特征值/特征向量统计做姿态描述子；滑窗统计 + SVM/随机森林分类。
- 在 MM-Fi 数据集 27 类活动（含康复类 13 类）达 90.3% 准确率，超过骨架基线 —— 证明**不重建骨架**也能区分姿态类。
- 计算量：图拉普拉斯特征分解是 O(n³) 对全帧太大，但对单个人体点簇（几百点）在 RK3588 上可行（NumPy 有 eigh）。
- 适用性：★★★☆ 跌倒不是其类别之一，但"每帧谱描述子 + 滑窗 + 浅层分类器"可作为我们特征升级路径；谱特征对姿态变化（直立 vs 水平）天然敏感。

## 5. Enhanced Sparse Point Cloud Processing for Privacy-aware Human Action Recognition（arXiv:2508.10469, 2025-08）
**PDF**: `2508.10469_稀疏点云动作识别_DBSCAN匈牙利KF.pdf`

- 毫米波稀疏点云，系统评测 **DBSCAN × 匈牙利关联 × 卡尔曼滤波** 三种组件各自及组合在 HAR 上的贡献。
- **直接对应我们 pipeline 的三个 stage**（候选聚类 / 帧间关联 / 轨迹平滑），其消融结论（哪一环提升最大）可指导我们调参优先级。
- 适用性：★★★★ 工程参考价值高；传感器稀疏度与我们不同（毫米波几十点 vs IFW192S 上万点），但其组件选择与组合结论通用。

## 6. Online Fall Detection using Recurrent Neural Networks（arXiv:1804.04976, 2018）
**PDF**: `1804.04976_在线跌倒检测RNN.pdf`

- UP-Fall 数据集上的 RGB-D/IMU/可穿戴多模态 LSTM 跌倒分类，重点是 **online**（滑窗判断而非事后整段）。
- 对 "online vs 整段离线"、"滑窗长度与报警延迟权衡" 的分析对我们 WebUI 显示和事件确认延迟有直接参考。
- 适用性：★★☆ 方法（LSTM）首版不用，但 online 检测的时序口径（报警延迟定义、事件起止标注）值得对齐。

## 7. Fall detection using multimodal data（arXiv:2205.05918, 2022）
**PDF**: `2205.05918_多模态跌倒检测.pdf`

- 多模态跌倒数据集与基线（RGB + 深度 + IMU），UP-Fall 类工作。
- 适用性：★☆ 主要价值是了解公开数据集的结构与标注方式，帮助我们设计自己的 `captures/` + 人工标签格式。

## 检索中确认"没有"的东西

- arXiv 无 **光学 3D LiDAR 跌倒检测** 的已发表主打论文（搜 `fall detection + lidar/point cloud`，命中的全是毫米波或深度相机）。说明本方向仍偏工程/空白，我们的规则管线属合理切入。
- 已发表 HAR（如 MM-Fi 基准）大多**不含"跌倒"类别**——要升级学习模型仍需自己采数据。
