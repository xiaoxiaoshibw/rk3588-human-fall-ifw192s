# PLANE-01 R3 · 小目标实时绿框（雷达 3D 盒 + 相机 2D 框）

本目录只读消费 `data/sessions/<sid>/`（`meta.json` / `points.bin` / `camera.mjpeg` /
`camera_frames.jsonl`），不写会话数据、不部署、不采集。

面向场景：10 Hz 固态 LiDAR（IFW192S，192×256 射线格）+ USB 相机，**同一段 5 s 里有一个被抛出、
滑翔、落到桌面后静止的纸飞机**，要求逐帧用绿色 3D 有向包围盒框住它，并把点云和视频并排放在
一个 HTML 里实时回放对比。

## 用法

```bash
# 1) 单元测试（仓库根目录）
python -B -W error -m unittest discover -s sidequests/plane_track/r03 -p "test_*.py"

# 2) 跑检测 + 导出证据 + 生成自包含对比页
python -B sidequests/plane_track/r03/make_plane_page.py \
  --session data/sessions/cap_20261023_215952 \
  --out     docs/evidence/2026-10-23_plane215952_realtime \
  --page    pc_apps/console/plane01_pages/cap_20261023_215952/compare.html

# 3) 页面自检（DATA 结构 / 框坐标 / 时间单调 / 内联脚本语法）
node sidequests/plane_track/r03/check_page.js pc_apps/console/plane01_pages/cap_20261023_215952/compare.html
```

输出：`compare.html`（单文件，内含 MP4 base64 + 背景点云 int16 + 逐帧检测）、
`detections.json`、`contact_sheet.png`、`camera_<sid>.mp4`。

## 算法（逐帧、只用历史帧）

1. **射线格**：点 → `cell = ring*256 + col(az)`。同一射线跨帧可比，不做体素配准。
2. **背景**：前 `--bg-window`（默认 21）帧按射线取距离中位数、方向取单位向量均值，
   得到每条射线的背景点（距离 × 方向）。窗口结束后**冻结**。
   为什么不是逐帧中位数：每帧 3.7 万有效点，逐格 31 帧中位数实测 245 ms/帧，实时性不够；
   而本段目标第 24 帧才出现，启动窗口不丢目标。
3. **前景**：① 同射线距离比背景近 > `drop`(0.12 m)；② 3D 上 `tau`(0.035 m) 内找不到背景点
   （KD 树，scipy 缺失时退化为体素哈希）。两条并集——② 能抓到“贴桌面、距离几乎不变”的目标。
4. **聚类**：`eps`(0.09 m) 网格单链接并查集；`≥16` 点、AABB 跨度 `≤0.70 m`、距离 `≤8 m`。
5. **关联**：最近邻 + 0.75 m 门限；命中 ≥4 或单帧位移 ≥0.30 m → **confirmed**（绿实线），
   否则 **tentative**（琥珀虚线）。
6. **包围盒**：PCA 有向盒；中心取投影区间中点（点集偏一侧时也贴紧），半长 = 区间半宽 + 2 cm。
7. **相机 2D**：时域中值背景 → 帧差(>22) → 连通域（10–8000 px、峰值 ≥45）→ 一对一贪心关联
   （代价 = 位移 + 200·|log 面积比|）→ 取“够长且真的移动过”的那条轨迹。

## 页面

- 左：canvas 2D 自写透视渲染（z-buffer 点泼溅），背景点云 + 目标点 + 绿色 OBB + 历史轨迹；
- 右：`<video>`（960×540，H.264）+ 覆盖层 canvas 画绿色 2D 框；
- 同一会话时钟：雷达帧按源帧时间驱动，相机按“落地时刻锚定”的偏移（本段 1.065 s）对齐；
- `?t=2.62` 深链到指定时刻，`?yaw=&pitch=&dist=` 换视角（截图/复核用）；
- 时间轴按帧状态着色（建背景 / 无目标 / 候选 / 确认），可拖拽、单帧步进、倍速、循环。

## 诚实边界

- 绿框是**几何包围盒**，不是“已识别为纸飞机”；目标语义来自用户口头标注，无分类器、无 GT。
- 背景 = 启动窗口建立后冻结：长时场景必须周期重估，本工具不声称支持。
- 相机与雷达**无硬件同步**（偏移由起飞/落地两个事件锚定，±1 帧）；相机与雷达**无投影标定**，
  2D 框与 3D 框各自独立，不能互相当真值。
- 单帧耗时只在本机 PC 实测（Python 3.12 / NumPy 1.26），**不代表板端 ARM 性能**。
- 1 段 5 s、1 个目标、1 次抛掷：不构成任何召回/精度/误报指标。
