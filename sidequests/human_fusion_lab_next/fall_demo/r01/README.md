# 守望 · 离线跌倒识别 Demo

双击 `start_demo.bat`，然后打开 http://127.0.0.1:8920/ 。已有服务运行时直接打开网址即可。停止本机服务可关闭对应终端；本次工具托管服务由执行工具管理。

先点“播放”观看完整过程，也可以点“跳到告警”。场景菜单提供跌倒恢复、正常行走、缓慢坐下、遮挡、初始低姿态、快速主动躺下误报反例。可拖动时间轴、逐帧检查、重置、标记告警已查看。标记仅保留在当前页面/场景，重置或切换场景会清除，不对外发送任何通知。

所有点云与目标 ID 均为合成已知目标；没有接入真实人体检测/分割、真实身份关联或实际跌倒录像。原 core/features.py 与 core/fall_state.py 只读复用，默认生产确认开关未修改；仅合成 fixture 开启确认。数据为逐帧顺序计算后导出，浏览器回放，不因 seek 重新累积确认票。

生成器以独占写入保护 data.json/manifest.json，不应覆盖重跑；修改实验需新目录。SHA 为同目录清单对数据的一致性校验，不是对恶意同时篡改清单和数据的签名认证。页面仅绑定本机，未部署。
